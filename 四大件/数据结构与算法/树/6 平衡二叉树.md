> 查找效率稳定在$O(logN)$
> 缺点：平衡性限制太严格，最坏每两次插入操作就需要调整，不适用于动态查找

# 基本概念

**平衡因子**：balance factor，一般定义为左子树高度减去右子树高度

平衡二叉树：AVL树，就是每个节点的balance factor的绝对值小于等于1的二叉树，需要在每次插入删除操作之后调整**最小不平衡树**以维护每个节点的balance factor在-1，0，1之间

**最小不平衡树**：插入后破坏平衡的节点为问题节点（trouble），离问题节点trouble最近的balance factor不正常的祖先节点就是发现者（finder），最小不平衡树就是以finder为根节点的不平衡的二叉子树，finder至少是trouble的爷爷

# 调整原理

> 无论是插入还是删除都可能产生最小不平衡树，需要对最小不平衡树进行调整以维护平衡因子，有时即便不需要调整树的结构，也需要更改平衡因子

## 节点的结构

需要在节点中增加bf（平衡因子），以判断以这个节点为根节点的树是否平衡

```Cpp
struct TreeNode{
	DataType data;
	struct TreeNoe* left,*right;
	int h;    //以该节点为根节点的子树的高度
}
```

## 调整策略

有**左旋**和**右旋**两种操作调整树的结构

这里把空节点也看作一个节点，即每个非空节点都有两个儿子，可能有“空儿子”

### 左旋

设需要调整的树的根节点为`T`，`T`的右儿子为`R`，`R`的左儿子为`Rl`，需要让`Rl`移给`T`作为`T`的左儿子，再让`T`作为`R`的右儿子，调整后原来的`R`作为调整后的树的根节点

![[左旋.png]]

图中三角形代表子树

```Cpp
TreeNode* LeftRotate(TreeNode* T){
	TreeNode* R=T->right;
	T->right=R->left;
	R->left=T;
	//重新求高度
	T->h=max(T->left->h,T->right->h)+1;
	R->h=max(R->left->h,R->right->h)+1;
	return R;
}
```

### 右旋

设需要调整的树的根节点为`T`，T的左儿子为`L`，`L`的右儿子为`Lr`，需要让`Lr`作为`T`的左儿子，再让`T`作为`L`的右儿子，调整后原来的`L`作为调整后的树的根节点

![[右旋.png]]

若`Rl`为空：![[右旋_1.png]]，N代表“空儿子”

```Cpp
TreeNode* RightRotate(TreeNode* T){
	TreeNode* L=T->left;
	T->left=L->right;
	L->right=T;
	//重新求高度
	T->h=max(T->left->h,T->right->h)+1;
	L->h=max(L->left->h,L->right->h)+1;
	return L
}
```

## 最小不平衡树的调整

最小不平衡树有两种情况，一种是左子树高度大于右子树高度，即根节点的bf大于1，另一种是右子树高度大于左子树高度，即根节点的bf小于-1

设最小不平衡树的根节点为`finder`

### 根节点的bf大于1

很明显问题出在finder的左子树上，需要讨论finder的左儿子的bf

设finder的左儿子为`L`

由于finder是离trouble最近的bf不正常的节点，所以finder的子孙节点的bf都是正常的，也就是-1，0，1三种情况

finder的左儿子L的bf只可能为==-1或1==，不可能为0，假设插入前L的bf为1，finder的bf为1，插入节点插在L的右子树上，插入之后L的bf变为0，但以L为根节点的子树的高度没有改变，finder的bf就不会改变，也就是插入之后没有产生最小不平衡树，所以不可能为0

![[L的bf为0的假设.png]]

图中m表示子树的高度

#### LL

> 根节点的左儿子的bf为1

说明插入节点在L的左儿子上，L的bf与finder的bf同号，只需要对finder进行右旋调整

![[L的bf为1.png]]

```Cpp
TreeNode* LLadjust(TreeeNode* T){
	T=RightRotate(T);    //直接右旋
	return T;
}
```

#### LR

> 根节点的左儿子的bf为-1

说明插入节点在L的右儿子上，L的bf与finder的bf异号，若直接对finder进行右旋，调整之后仍然不平衡，需要先对L进行左旋，再对finder进行右旋调整

![[L的bf为-1.png]]

```Cpp
TreeNode* LRadjust(TreeNode* T){
	T->left=LeftRotate(T->left);
	T=RightRotate(T);
	return T;
}
```

### 根节点的bf小于-1

与根节点的bf大于1的LeftAdjust类似

设R为根节点finder的右儿子

#### RR

> 根节点的右儿子的bf为-1

R的bf和finder的bf同号，直接将finder左旋

```Cpp
TreeNode* RRadjust(TreeNode* T){
	T=LeftRotate(T);
	return T;
}
```

#### RL

> 根节点的右儿子的bf为1

R的bf和finder的bf不同号，先将R右旋，再将finder左旋

```Cpp
TreeNode* RLadjust(TreeNode* T){
	T->right=RightRotate(T->right);
	T=LeftRotate(T);
	return T;
}
```

# 插入

> 继承二叉树递归插入的思想，若需要插入的树为空，则增加一个节点并插入，插入之后需要调整以维持平衡性

1. 每层插入后检查该节点是否失衡，若失衡，检查是（LL，LR，RR，RL），根据情况进行调整
2. 最后重新计算节点的高度

## 实现

```Cpp
bool isInsert=true;    //是否插入成功

int getHeight(TreeNode* t){
	if(!t)return 0;
	return max(getHeight(t->left),getHeight(t->right))+1;
}

TreeNode* InsertAVL(TreeNode* t,DataType key){
	if(!t){
		TreeNode* p=new TreeNode;
		p->data=key;
		p->left=p->right=nullptr;
		return p;
	}
	if(key<t->data){    //递归在左子树插入
		t->left=InsertAVL(t->left,key);
		if(!isInsert)return t;    //插入失败就不做处理直接返回
		if(getHeight(t->left)-getHeight(t->right)>1){    //失衡
			if(key<t->left->data){    //LL
				t=LLadjust(t);
			}
			else {     //LR
				t=LRadjust(t);
			}
		}
	}
	else if(key>t->data){    //递归在右子树插入
		t->right=Insert(t->right,key);
		if(!isInsert)return t;    //插入失败就直接返回
		if(getHeight(t->right)-getHeight(t->left)>1){    //失衡
			if(key>t->right->data){    //RR
				t=RRadjust(t);
			}
			else {
				t=RLadjust(t);
			}
		}
	}
	else {    //插入失败
		isInsert=false;
	}
	//重新计算高度
	t->h=max(getHeight(t->left),getHeight(t->right))+1;
	return t;
}
```

# 删除

> 也是继承二叉树的删除思想

- 左子树删除一个节点相当于右子树插入一个节点，RR/RL
	- 若R的左子树比右子树高，是RL
	- 若R的右子树比左子树高，是RR
	- 一样高，认为是RR
- 右子树删除一个节点相当于左子树插入一个节点，LL/LR 
	- 若L的左子树比右子树高，是LL
	- 若L的右子树比左子树高，是LR
	- 一样高，认为是LL

1. 每层插入后检查该节点是否失衡，若失衡，检查是（LL，LR，RR，RL），根据情况进行调整
2. 最后重新计算节点的高度

## 实现

```Cpp
bool isDelete=true;

int getHeight(TreeNode* t){
	if(!t)return 0;
	return max(getHeight(t->left),getHeight(t->right))+1;
}

TreeNode* DeleteAVL(TreeNode* t,key){
	if(!t){    //删除失败
		isDelete=false;
		return t;
	}
	if(key<t->data){
		t->left=DeleteAVL(t->left,key);
		if(!isDelete)return t;    //删除失败直接返回
		if(getHeight(t->right)-getHeight(t->left)>1){    //失衡
			TreeNode* R=t->right;
			if(getHeight(R->right)>=getHeight(R->left)){    //RR
				t=RRadjust(t);
			}
			else {     //RL
				t=RLadjust(t);
			}
		}
	}
	else if(key>t->data){
		t->right=DeleteAVL(t->right,key);
		if(!isDelete)return t;    //删除失败直接返回
		if(getHeight(t->left)-getHeight(t->right)>1){    //失衡
			TreeNode* L=t->left;
			if(getHeight(L->left)>=getHeight(L->right)){    //LL
				t=LLadjust(t);
			}
			else {    //LR
				t=LRadjust(t);
			}
		}
	}
	else {    //找到了需要删除的节点
		if(t->left&&t->right){    //左右子树都存在
			TreeNode* leftMax=findMax(t->left);
			t->data=leftMax->data;
			t->left=Delete(t->left,leftMax->data);    //左子树有删除
			if(getHeight(t->right)-getHeight(t->left)>1){    //失衡
				TreeNode* R=t->right;
				if(getHeight(R->right)>=getHeight(R->left)){    //RR
					t=RRadjust(t);
				}
				else {     //RL
					t=RLadjust(t);
				}
			}
		}
		else if(t->left){    //左子树存在
			TreeNode* tmp=t;
			t=t->left;
			delete tmp;
		}
		else {    //右子树存在(即便为空)
			TreeNode* tmp=t;
			t=t->right;
			delete tmp;
		}
	}
	//重新计算高度
	if(t)r->h=getHeight(t);
	return t;
}
```

# 由BST建AVL

> 利用二叉查找树已经有序的特性

- 通过对原来的BST中序遍历得到有序序列（从小到大）
- 通过有序序列递归地建树，每次选取序列段中的下标在中间的节点进行插入，然后**递归**地通过这个节点在序列中的==左边的序列段==建立这个节点的==左子树==，通过这个节点在序列中的==右边的序列段==建立这个节点的==右子树==

假设给定一颗二叉查找树root，需要建立avl树

```Cpp
vector<TreeNode*> inorder;    //记录有序序列

TreeNode* getAVL(TreeNode* root){
	InOrderTraversal(root);
	return buildAVL(0,inorder.size()-1);
}

void InOrderTraversal(TreeNode* root){
	InOrderTraversal(root->left);
	inorder.push_back();
	InOrderTraversal(root->right);
}

TreeNode* buildAVL(int left,int right){
	if(left>right)return nullptr;
	int middle=(left+right)/2;
	TreeNode* t=new TreeNode;
	t->val=inorder[middle]->val;
	t->left=buildAVL(left,middle-1);
	t->right=buildAVL(middle+1,right);
	return t;
}
```
