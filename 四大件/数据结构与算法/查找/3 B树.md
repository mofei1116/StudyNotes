> 多路平衡查找树，一个节点可以包含多个数据，用于管理外存数据

# 基本概念

2-3树：最多有两种节点，3阶B树（3路平衡查找树）
2-节点：节点有1个数据，2个孩子
3-节点：节点有2个数据，3个孩子

2-3-4树：最多有三种节点，4阶B树（4路平衡查找树）
2-节点：节点有1个数据，2个孩子
3-节点：节点有2个数据，3个孩子
4-节点：节点有3个数据，4个孩子

2-3-4-...-m树同理，阶数是树的度

若内存和外存一次可以交换$m$个数据则可以构造$m+1$阶树，一个节点最多包含$m$数据

有$n$个数据的$m$阶树的高度约为$log_{m}N$

用B树存**关键字**和数据的**地址**构成的索引

# 性质

一颗m阶B树：
1. 树中的节点最多有$m$个孩子，$m-1$个数据域，节点的数据域个数等于孩子个数-1
2. 根节点至少有$1$个数据域和$2$个孩子，非根节点最少有$ceil(m/2)$个孩子，$ceil(m/2)-1$个数据域
3. 节点内部的多个数据有序，节点之间也有序（中序遍历序列有序）；中序遍历B树：遍历节点中的一个数据的左子树，遍历节点中这个数据，遍历节点中这个数据的右子树，遍历节点中下一个数据
4. 平衡性：绝对平衡，子树高度相同，内部终端节点都在同一层

# 结构

```Cpp
//5阶B树
#define M 5

struct BTnode{
	int key[M+1];    //数据域数组，从下标1开始存
	BTnode* child[M+2];    //孩子指针数组，从下标1开始存
	//下标i的数据的左孩子指针的下标为i
	int size;    //数据个数
	BTnode* parent;
};
```

# 查找

要查找数据`d`是否在B树中

1. 在节点中找到第一个大于等于`d`的数据`a`
2. 若`a==d`查找成功，若`a>d`，进入数据`a`的左子树查找，直到查找成功或走到失败节点（内部终端节点的空孩子）

## 实现

```Cpp
//在root中查找数据d所在的节点k，在节点p中的下标x，返回是否查找成功

bool searchKey(BTnode* root,int d,BTnode* &k,int &x){
	BTnode* p=root;    //指示指针
	BTnode* pf=nullptr;
	int i=0;
	while(p){
		pf=p;
		//在节点p中找到第一个大于等于d的数据
		for(i=1;i<=p->size;i++){
			if(p->key[i]>=d){
				break;
			}
		}
		if(i>p->size||p->key[i]>d){    //越界或大于d
			p=p->child[i];
		}
		else {    //查找成功
			k=p;
			x=i;
			return true;
		}
	}
	//查找失败，k,x赋值为要插入的位置
	k=pf;
	x=i;
	return false;
}
```

# 插入

需要找到对应的**终端节点**和节点中数据域数组对应的**下标**

1. 用`p`指示指针查找，用`pf`指针指向`p`的父节点，当`p`为失败节点时`pf`就是要插入的节点 
2. 在节点的数据域数组中执行顺序表的插入，插入数据`d`逻辑上需要多一个孩子`np`
3. 若插入后节点中数据域数量没超过上限（m-1），不需要调整；若插入后节点中数据域数量超过了上限（m-1），需要调整，循环**分裂向上插入**（回溯分裂法）

## 回溯插入法

设要插入数据的节点为`p`

从下标`s=ceil(m/2)`将节点的数据域数组分开（均分保数据量下限），下标$[1,x-1]$的数据保留在节点中，下标`x`的数据**插入**到这个节点的父节点`pf`中，下标$[x+1,m]$的数据保存在新建节点`np`中，将节点`np`作为父节点`pf`中刚插入的数据的右子树

直到插入的节点中的数据域个数不超过上限（m-1）或要插入的节点`pf`是空节点，若`pf`是空节点，新建一个节点保存要插入的数据，将新建的节点作为根节点

## 主动分裂法

在找插入位置的同时，把经过的有分裂风险的节点（数据域个数已经达到上限）顺便分裂

缺点：浪费时间

## 实现

```Cpp
BTnode* createNode(BTnode* l,BTnode* r,int d){
	BTnode* s=new BTnode;
	s->size=1;
	s->key[1]=d;
	s->child[1]=l;
	s->child[2]=r;
	if(l)l->parent=s;
	if(r)r->parent=s;
	s->parent=nullptr;
	return s;
}

void insertKey(BTnode* &root,int d){
	BTnode* k;    //要插入的节点
	int x;    //要插入的节点中数据域数组的下标
	BTnode* np=nullptr;    //多一个数据就多一个孩子，插到x+1位置
	if(!root){    //空树插入
		root=createNode(nullptr,nullptr,d);
		return;
	}
	if(searchKey(root,d,k,x)){    //查找成功，不需要插入
		return;
	}
	while(true){
		//顺序表插入
		for(int i=k->size;i>=x;i--){
			k->key[i+1]=k->key[i];
			k->child[i+2]=k->child[i+1];
		}
		k->key[x]=d;
		k->child[x+1]=np;
		if(np)np->parent=k;
		k->size++;
		if(k->size<=M-1){    //没超上限
			break;
		}
		else {    //超过了上限，需要调整
			int s=(M+1)/2;    //分裂位置
			d=k->key[s];
			//[x+1,M]分裂到np节点
			k->size=s-1;
			np=new BTnode;
			for(int i=1;s+i<=M;i++){
				np->key[i]=k->key[s+i];
				np->child[i]=k->child[s+i];
				if(np->child[i])np->child[i]->parent=np;
			}
			np->size=M-s;
			np->child[np->size+1]=k->child[M+1];
			if(np->child[np->size+1])np->child[np->size+1]->parent=np;
			np->parent=k->parent;
			//继续插入
			if(k->parent){
				searchKey(root,d,k,x);
			}
			else {
				root=createNode(k,np,d);
				break;
			}
		}
	}
}
```

# 删除

1. 在树中查找要删除的数据`d`所在的节点`p`
2. 执行删除：
	1. `p`是内部终端节点，直接删掉数据`d`（顺序表的删除），删一个数据逻辑上也要删除一个孩子；若节点内数据个数少于下限（$ceil(m/2)-1$），需要调整：
		1. 找左右相邻的大于下限的兄弟借一个数据，找左兄弟借要借最大值，找右兄弟借要借最小值
		2. 若两个兄弟的数据个数都都刚好是下限，将节点`p`和其中一个兄弟以及父节点中的一个数据合并，此时父节点的数据个数可能低于下限，对父节点循环向上调整，当父节点是根节点或父节点中数据个数不低于下限时停止，若父节点是根节点且只有一个数据，合并后需要换根
	2. `p`不是终端节点，找到中序遍历序列中的后继（找前驱需要遍历），后继数据一定在终端节点上，数据复制到`p`中，再删除后继数据，转化成删除内部终端节点中数据的情况


## 实现

```Cpp
void remove(BTnode* k,int x){    //顺序表删除
	for(int i=x;i<=k->size;i++){
		k->key[i]=k->key[i+1];
		k->child[i]=k->child[i+1];
	}
	k->size--;
}

//需要借的节点，左右兄弟节点，节点k在其父节点中的孩子数组中的下标x
void Borrow(BTnode* k,BTnode* lSibling,BTnode* rSibling,int i){
	BTnode* kf=k->parent;
	if(lSibling&&lSibling->size>(M+1)/2-1){    //可以找左兄弟借
		//节点k中空出第一个数据和孩子
		k->child[k->size+2]=k->child[k->size+1];
		for(int j=k->size;j>=1;j--){
			k->key[j+1]=k->key[j];
			k->child[j+1]=k->child[j];
		}
		k->key[1]=kf->key[i-1];
		kf->key[i-1]=lSibling->key[lSibling->size];
		k->child[1]=lSibling->child[lSibling->size+1];
		if(k->child[1])k->child[1]->parent=k;
		lSibling->size--;
		k->size++;
	}
	else {    //可以找右兄弟借
		k->size++;
		k->key[k->size]=kf->key[i];
		kf->key[i]=rSibling->key[1];
		k->child[k->size+1]=rSibling->child[1];
		if(k->child[k->size+1])k->child[k->size+1]->parent=k;
		for(int j=2;j<=rSibling->size;j++){
			rSibling->key[j-1]=rSibling->key[j];
			rSibling->child[j-1]=rSibling->child[j];
		}
		rSibling->child[rSibling->size]=rSibling->child[rSibling->size+1];
		rSibling->size--;
	}
}

void Adjust(BTnode* &root,BTnode* k);

//根节点，合并的左边节点，合并的右边节点，父节点中需要合并的数据的下标
void Merge(BTnode* &root,BTnode* x,BTnode* y,int j){
	BTnode* kf=x->parent;
	//父节点中的数据key[j]合并到节点x
	x->size++;
	x->key[x->size]=kf->key[j];
	//右节点合共到左节点
	for(int i=1;i<=y->size;i++){
		x->size++;
		x->key[x->size]=y->key[i];
		x->child[x->size]=y->child[i];
		if(x->child[x->size])x->child[x->size]->parent=x;
	}
	x->child[x->size+1]=y->child[y->size+1];
	if(x->child[x->size+1])x->child[x->size+1]->parent=x;
	delete y;
	y=nullptr;
	remove(kf,j);    //删除kf中j位置的数据
	kf->child[j]=x;    //合并后的节点挂在父节点j位置
	if(!kf->parent){    //kf是根节点
		if(kf->size<1){    //小于最小值
			root=x;
			x->parent=nullptr;
			delete kf;
			kf=nullptr;
		}
	}
	else{    //不是根节点
		if(kf->size<(M+1)/2-1){    //小于最小值
			Adjust(root,kf);
		}
	}
}

void Adjust(BTnode* &root,BTnode* k){
	//找左右兄弟
	BTnode* lSibling=nullptr,*rSibling=nullptr;
	int i;    //k在其父节点的孩子数组中的下标
	BTnode* kf=k->parent;
	for(i=1;i<=kf->size;i++){
		if(kf->child[i]==k)break;
	}
	if(i>1)lSibling=kf->child[i-1];
	if(i<kf->size)rSibling=kf->child[i+1];
	if((lSibling&&lSibling->size>(M+1)/2-1)||
		(rSibling&&rSibling->size>(M+1)/2-1)){    //可以找兄弟借一个
		Borrow(k,lSibling,rSibling,i);
	}
	else {    //兄弟借不了，找一个兄弟合并，至少有一个兄弟存在
		if(lSbling){    //和左兄弟合并
			Merge(root,lSibling,k,i-1);
		}
		else {    //和右兄弟合并
			Merge(root,k,rSibling,i);
		}
	}
}

void delteKey(BTnode* &root,int d){
	BTnode* k;    //要删除的数据所在的节点
	int x;    //要删除的数据在节点数据域数组中的下标
	if(!searchKey(root,d,k,x)){    //查找失败
		return;
	}
	if(k->child[1]){    //k不是终端节点
		BTnode* p=k->child[x+1];    //指示指针
		while(p->child[1])p=p->child[1];
		k->key[x]=p->key[1];
		k=p;
		x=1;
	}
	//k是终端节点
	remove(k,x);
	if(!k->parent){    //删除的节点是根节点
		if(k->size<1){    //删除后低于下限
			delete k;
			root=k=nullptr;
		}
	}
	else {    //删除的节点不是根节点
		if(k->size<(M+1)/2-1){    //删除后低于下限，需要调整
			Adjust(root,k);
		}
	}
}
```
