# 基本概念

- 查找：在数据集合中查找满足某种条件的数据元素，有查找成功和查找失败两种可能
- 数据：数据由多个数据项构成
- 静态查找：查找的数据集合基本不变，常用顺序，折半，哈希查找
- 动态查找：查找的数据集合会频繁变动，常用树形，哈希查找
- 关键字key：绝对不重复的数据项
- 查找长度：一次查找过程中比较的次数
- 平均查找长度：等概率下多次查找比较次数的平均值，有$n$个数据，第$i$个数据被查找的概率是$p_i$，查找长度是$c_i$，$ASL_{成功}={p_1}{c_1}+{p_2}{c_2}+...+{p_n}{c_n}$

# 顺序查找

在顺序表中从前往后顺序依次比较，对数据集合的有序性没有要求

$ASL_{成功}=(c_1+c_2+...+c_n)/n$
$ASL_{失败}=n+1$
