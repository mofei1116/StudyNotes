# 邻接矩阵

> 适合稠密图

## 结构

### 顶点结构

用==顺序表==存顶点集，每个顶点包含数据==data==，顶点编号==id==（大部分情况下和顶点在数组中的下标对应）

```Cpp
struct Vertex{
	int id;
	DataType data;
};
```

### 边结构

用边的两个顶点在顺序表中的==索引==表示边，由于一条边包含两个索引，所以用一个二维数组来表示E集，边存在就填1，不存在就填0（自己指向自己的边）或INF（不同顶点之间的边）

`typedef int Edge;    //表示边的存在状态（0,1,INF）`

### 图结构

封装好顶点集和边集，用==vertexNum==表示顶点个数，==edgeNum==表示边的条数，==isDirect==表示是否是有向图

```Cpp
struct MGraph{
	Vertex nodes[MaxNumber];
	Edge edges[MaxNumber][MaxNumber];
	int vertexNum;
	int edgeNum;
	bool isDirect;
};
```

## 初始化图

把边集里面自己指向自己的边填为0，不同顶点之间的边填为无穷大，假设已确定所有顶点

```Cpp
void initGraph(MGraph* graph,int vNum,bool isDirect,DataType vertex[]){
	graph->vertexNum=vNum;
	greph->edgeNum=0;
	graph->isDirect=isDirect;
	for(int i=0;i<vertexNum;i++){
		//初始化顶点集
		graph->nodes[i].id=i;
		graph->nodes[i].data=vertex[i];
		for(int j=0;j<vertexNum;j++){    //初始化边集
			if(i==j)graph->edges[i][j]=0;
			else graph->edges[i][j]=INFINITY;
		}
	}
}
```

## 添加边

假设边有权重`weight`，若不是网络就填1，边的起点为`v1`（索引），边的终点为`v2`（索引），若是无向图，添加一条边要添加对应的相反的边

```Cpp
void InsertEdge(MGraph* graph,int v1,int v2,int weight){
	graph->edges[v1][v2]=weight;
	if(!graph->isDirect){
		graph->edges[v2][v1]=weight;
	}
	graph->edgeNum++;
}
```

# 邻接表

## 结构

### 边结构

实际上是边的==弧头==和弧尾表示一条==出度==边，包含边的权值`weight`（如果是无权图就不需要），顶点的编号（弧头在数组中的下标）`id`，指向下一个弧头的指针`next`

```Cpp
struct Edge{
	int weight;
	int id;
	Edge* next;
}
```

### 顶点结构

用顺序表存顶点，每个顶点包含编号`id`，顶点的数据`data`，顶点的第一条出度边（实际上是弧头）`firstEdge`

逆邻接表：保存入度

```Cpp
struct Vertex{
	int id;
	Datatype data;
	Edge* firstEdge;
}
```

### 图结构

包含顶点集数组`nodes`，顶点数量`vertexNum`，边数量`edgeNum`，是否是有向图`isDirect`
```Cpp
struct LGreaph{
	Vertex* nodes;
	int vertexNum;
	int edgeNum;
	bool isDirect;
}
```

## 初始化图

给顺序表中的顶点初始化`data`和`id`，`firstEdge`初始化为NULL

```Cpp
void initGraph(LGraph* graph,bool isDirect,int vNum,int edgeNum,DataType vertex[]){
	graph->isDirect=isDirct;
	graph->vertexNum=vNum;
	graph->edgeNum=0;
	for(int i=0;i<graph->vertexNum;i++){    //初始化顶点集
		graph->nodes[i].id=i;
		graph->nodes[i].data=vertex[i];
		graph->nodes[i].firstEdge=NULL;
	}
}
```

## 添加边

用头插法插在出度链表的表头，维护`edgeNum`，如果是无向图，需要添加相反的出度边

```Cpp
Edge* createEdge(int w,int v){
	Edge* e=malloc(sizeof(Edge));
	e->weight=w;
	e->id=v;
	e->next=NULL;
	return e;
}

void InsertEdge(LGraph* graph,int weight,int v1,int v2){
	Edge* e=createEdge(weight,v2);
	e->next=graph->nodes[v1].firstEdge;
	graph->nodes[v1].firstEdge=e;
	graph->edgeNum++;
	if(!graph->isDirect){    //添加相反的出度边
		e=createEdge(weight,v1);
		e->next=graph->nodes[v2].firstEdge;
		graph->nodes[v2].firstEdge=e;
	}
}
```

# 十字链表

> CrossGraph只能存有向图

若用邻接表和逆邻接表存有向图，有n条边就需要存2n个边结构
用十字链表存有向图，有n条边只需要存n个边结构

## 结构

### 边结构

一条边含弧尾节点的编号`tail`，弧头节点的编号`head`，指向`tail`下一条出度边的指针`tailNext`，指向`head`下一条入度边的指针`headNext`，边的权重`weight`

```Cpp
struct Edge{
	int tail;
	Edge* tailNext;
	int head;
	Edge* headNext;
	int weight;
}
```

### 顶点结构

一个顶点含顶点编号`id`，顶点数据`data`，指向第一条入度边的指针`firstIn`，指向第一条出度边的指针`firstOut`

```Cpp
struct Vertex{
	int id;
	DataType data;
	Edge* firstIn;
	Edge* firstOut;
}
```

### 图结构

用顺序表存储顶点集

```Cpp
struct CGraph{
	int vertexNum;
	int edgeNum;
	Vertex* nodes;
}
```

## 初始化图

```Cpp
void initGraph(CGraph* graph,int vNum,DataType vertex[]){
	graph->vertexNum=vNum;
	graph->edgeNum=0;
	for(int i=0;i<graph->vertexNum;i++){    //初始化顶点结构
		graph->id=i;
		graph->nodes[i].data=vertex[i];
		graph->nodes[i].firstIn=nullptr;
		graph->nodes[i].firstOut=nullptr;
	}
}
```

## 添加边

用头插法插入入度链表和出度链表

```Cpp
void InsertEdge(CGraph* graph,int t,int h,int w){
	Edge* e=new Edge;
	if(!e)return;
	graph->edgeNum++;
	e->tail=t;
	e->head=h;
	e->weight=w;
	//头插法插入出度边
	e->tailNext=graph->nodes[e->tail]->firstOut;
	graph->nodes[e->tail]->firstOut=e;
	//头插法插入入度边
	e->headNext=graph->nodes[e->head]->firstIn;
	graph->nodes[e->head]->firstIn=e;
}
```

## 遍历所有出度

只需要从==firstOut==开始，沿着==tailNext==遍历到NULL

```Cpp
void traversalOut(CGraph* graph,int v){
	Edge* p=graph->nodes[v]->firstOut;
	while(p){
		visit(p);    //访问行为
		p=p->tailNext;
	}
}
```

## 遍历所有入度

只需要从==firstIn==开始，沿着==headNext==遍历到NULL

```Cpp
void traversalIn(CGraph* graph,int v){
	Edge* p=graph->nodes[v]->firstIn;
	while(p){
		visit(p);    //访问行为
		p=p->headNext;
	}
}
```

# 邻接多重表

> MultiGraph只能存无向图

用邻接表存无向图，有n条边就需要存2n个边结构
用邻接多重表存无向图，有n条边只需要存n个边结构

## 结构

### 边结构

```Cpp
struct Edge{
	int u,v;    //端点u,v
	int weight;
	edge* uNext;    //端点u的下条边
	edge* vNext;    //端点v的下条边
}
```

### 顶点结构

```Cpp
struct Node{
	int id;
	edge* first;
}
```

## 插边

```Cpp
void insertEdge(int u,int v,int w){
	Edge* e=newEdge(u,v,w);     //建边
	e.uNext=nodes[u].first;
	nodes[u].first=e;
	e.vNext=nodes[v].first;
	nodes[v].first=e;
}
```

## 遍历边

```Cpp
void traversalEdge(int a){
	Edge* p=nodes[a].first;
	while(p){
		visit(p);    //访问行为
		if(p.u==a){
			p=p.uNext;
		}
		else p=p.vNext;
	}
}
```

# 链式前向星

> 链式前向星是邻接表存储结构的一种变体结构，静态链表模拟链表，插入边模拟链表的头插

## 结构

### 边集数组

- 若是无向图，`E`数组的大小要开边的个数的两倍

```Cpp
struct edge{
	int to;    //出度边终点
	int weight;    //权值
	int next;    //和该边同起点的另一个边的下标指针
}E[MaxE];

int cnt;    //记录边集数组中边的个数
```

### 头节点数组

`head[i]`存以`i`为出度边起点的第一个出度边在边集数组`edge`中的下标，初始化为-1（非法下标）
一定要记住==初始化==

```Cpp
int head[MaxV];
```

## 插边

```Cpp
void add(int s,int e,int w){
	E[cnt].to=e;
	E[cnt].weight=weight;
	//模拟头插
	E[cnt].next=head[s];
	head[s]=cnt;
	cnt++;
}
```
