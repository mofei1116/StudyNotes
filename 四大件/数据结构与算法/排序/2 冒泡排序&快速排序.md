> 都是基于交换思想的算法

# 冒泡排序

## 实现

直接应用比较和交换的思想，对无序区中相邻的两个数据比较，若`a[j]<=a[j+1]`，不处理
若`a[j]>a[j+1]`，交换两个数

进行一轮冒泡排序后，无序区中最大的数在无序区最后一个位置
每一轮冒泡排序后，有序区+1，无序区-1，需要执行$n-1$轮

```Cpp
int a[maxNum];

void bubbleSort(int n){
	for(int i=n;i>=1;i--){    //枚举无序区右边界
		for(int j=1;j<=i-1;j++){
			if(a[j]>a[j+1]){
				int t=a[j];
				a[j]=a[j+1];
				a[j+1]=t;
			}
		}
	}
}
```

不优化：时间复杂度最好最坏都是$O(N^2)$

```Cpp title:"优化"
int a[maxNum];

void bubbleSort(int n){
	for(int i=n;i>=1;i--){    //枚举无序区右边界
		bool exchaged=false;    //标记一轮冒泡是否有交换
		for(int j=1;j<=i-1;j++){
			if(a[j]>a[j+1]){
				exchanged=true;
				int t=a[j];
				a[j]=a[j+1];
				a[j+1]=t;
			}
		}
		if(!exchaged)break;    //一轮冒泡没有交换说明已经有序了
	}
}
```

最好时间复杂度$O(N)$，最坏时间复杂度$O(N^2)$，空间复杂度$O(1)$，就地排序，稳定

# 快速排序

> 基于分治思想

## 实现

在待排序的序列中，选取一个基准数`p`，序列中小于等于`p`的数放在`p`前面，大于`p`的数放在`p`的后面，一轮排序后`p`在最终的位置上，即`p`有序，然后递归处理`p`前面的序列和`p`后面的序列

### 基准数的选取

理论上可以选任意位置
1. 选待排序区间的第一个数`a[l]`
2. 选待排序区间的最后一个数`a[r]`
3. 选待排序区间的中间的数`a[(l+r)/2]`

### 一轮交换排序

> 插空法

维护两个下标`i`和`j`，使得`i-1`开始的前缀序列都是小于等于`p`的数，`j+1`开始的后缀序列都是大于`p`的数，初始化`i=l,j=r`

若要选区间第一个数为基准数，此时`i`位置是空的，需要从`j`开始往前遍历找到第一个小于等于`p`的数填到`i`位置，`i++`，此时`j`位置空了，需要从`i`开始往后遍历找到第一个大于`p`的数填到`j`位置，`j--`，此时`i`位置又空了，循环直到`i==j`，将`p`填到`i`位置

```Cpp title:"以第一个数为基准数"
int a[maxNum];

void quickSort(int l,int r){
	if(l>=r)return;    //不需要排序直接退出
	int p=a[l];    //p为基准数，此时l位置空出来了
	int i=l,j=r;
	while(i<j){
		while(i<j&&a[j]>p)j--;    //找第一个小于等于p的数
		if(i<j){
			a[i]=a[j];    //此时j位置空了
			i++;
		}
		while(i<j&&a[i]<=p)i++;    //找到第一个大于p的数
		if(i<j){
			a[j]=a[i];    //此时i位置空了
			j--;
		}
	}
	a[i]=p    //此时i==j位置空了，将基准数填到i位置
	//递归处理子序列
	quickSort(l,i-1);
	quickSort(i+1,r);
}
```

每一层递归遍历的时间复杂度$O(N)$，递归层数最小$logN$，最大$N$

最好时间复杂度$O(NlogN)$，最坏时间复杂度$O(N^2)$，平均时间复杂度$O(NlogN)$，就地排序，最好空间复杂度$O(logN)$，最坏空间复杂度$O(N)$，不稳定
