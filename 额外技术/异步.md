> 不影响定时执行（如计时，怪物移动）的情况下，进行输入操作

### 主要函数

#### int _kbhit();

头文件：#include <conio.h>

作用：判断用户是否有输入（缓冲区是否有值），**非阻塞**地响应键盘输入事件

返回值：

0：用户没有输入（缓冲区没有值）

非0：用户有输入内容（缓冲区有值）

#### Sleep();

头文件：在Windows下：#include <windows.h>

作用：将进程挂起一段时间，以毫秒为单位，如Sleep(50)是将程序进程挂起50毫秒

### 利用Sleep()的异步原理

#### 原理
忽略程序运行时间，将程序生命周期划为不可再细分的==小时间段==，时间段的长度由Sleep(n)中的n决定，Sleep(100)就划分为无数个长度为0.1秒的时间段，在每个时间段的==端点==检查一次输入，程序在==端点==继续运行

根据不同大小的时间段执行定时的操作（计时，怪物移动函数等），该时间段长度是最小时间段长度的正整数倍

#### 案例
```C
```C
int count = 0;    //计数器
int time=0;    //计时器
char input;
while (1) {
    count++;    //每经过了一个最小时间段，计数器++
    Sleep(100);    //最小时间段长度为100毫秒
    
    if (count%5==0) {   //每间隔500毫秒执行一次该操作，该操作间隔的时间段是最小时间段的5倍
        // 每500毫秒打印一次---
        printf("---\n");
    }
    
    if(count%20==0)monsterMove();    //每间隔2秒执行一次怪物移动操作
    
    if(count%10)time++;    //每间隔1秒计时器++
    
    //当用户有输入时 执行这里的操作
    if (_kbhit()) { 
        //如果输入的是esc  结束循环,   否则打印输入的内容
        input = _getch();
        if (input == 27) break;
        else playerMove();    //玩家移动
    }
}
```
