> 线段树用来维护**区间信息**，大区间的信息可以由小区间合并得到
> 想清楚要维护什么信息，插入和查询要做什么事

# 基本概念

线段树是一种二叉搜索树

特征：
1. 用分治自顶向下建立，每次分治，左右子树各一半
2. 每个节点表示一个区间，叶子节点的区间只含一个元素
3. 除了最后一层，其他层都是满的，类似完全二叉树，可以用数组存树
4. `l`为左边界，`r`为右边界，
	1. 若`l==r`，该节点是叶节点
	2. 若`l<r`，该节点有两个子节点，左儿子区间为`l`~`mid`，右儿子区间为`mid+1`~`r`，`mid=(l+r)/2`
5. 区间修改，区间查询时间复杂度为$O(logN)$

# 结构

用数组存树，有$n$个元素需要开$4n$个节点大小的数组

证明：
假设$n=2^k$，最后一层有$2^k$个节点，则恰好为完全二叉树，所以所有节点的数目为$1+2+4+...+2^k=2^{k+1}-1$（等比数列求和），约等于$2n$
假设$n=2^k+C$，最后一层有$C$个节点，最后一层需要开$2^{k+1}$个空间，需要开的空间为$+2+4+...+2^{k+1}=2^{k+2}-1$，约等于$4n$
所以需要开$4n$大小的数组

```Cpp
int n;    //元素个数，也就是叶节点个数
const int MaxNum=n<<2;

struct TreeNode{
	int l,r;    //左右边界
	int sum;    //区间信息，以区间和为例
	int tag;    //懒标记
}tree[MaxNum];
```

## 建树

```Cpp
void Build(int t,int l,int r){    //节点编号，区间 [l,r]
	tree[t].l=l;
	tree[t].r=r;
	if(l==r){    //叶子节点
		tree[t].sum=a[l];
		return;
	}
	int mid=(l+r)/2;
	Build(t*2,l,mid);    //左子树
	Build(t*2+1,mid+1,r);    //右子树
	tree[t].sum=tree[t*2].sum+tree[t*2+1].sum;
}
```

建树时间复杂度$O(N)$

# 区间修改

> 单点修改看成是左右边界相同的区间修改

```Cpp
void Update(int t,int ml,int mr,int k){    //要修改的区间[l,r]每个数加上k
	if(tree[t].l==tree[t].r){    //叶子节点
		tree[t].sum+=k;
		return;
	}
	int mid=(tree[t].l+tree[t].r)/2;
	if(ml<=mid){    //左儿子的区间与[ml,mr]有交集
		Update(t*2,ml,mr,k);
	}
	if(mr>=mid+1){    //右儿子的区间与[ml,mr]有交集
		Update(t*2+1,ml,mr,k);
	}
	tree[t].sum=tree[t*2].sum+tree[t*2+1].sum;
}
```

时间复杂度$O(N)$，比枚举还慢点，除了要修改$r-l+1$个叶节点，还要修改上面的节点，枚举只需要枚举$r-l+1$个

## lazy-tag优化

`tag`记录区间的修改

当前节点的区间完全包含于要修改的区间，可以直接修改`tag`标记，不用往下修改子区间，当需要递归对子树进行查询或修改操作时将父节点的`tag`下传到左右子树

- **一定**记得下放后复原懒标记

```Cpp title:"down"
void down(int t){    //下传懒标记到左右儿子
	if(tree[t].tag==0)return;    //没有累积的修改，不需要下传
	int lchild=t*2,rchild=t*2+1;    //左右儿子
	//下传到左儿子
	tree[lchild].tag+=tree[t].tag;
	tree[lchild].sum+=(tree[lchild].r-tree[lchild].l+1)*tree[t].tag;
	//下传到右儿子
	tree[rchild].tag+=tree[t].tag;
	tree[rchild].sum+=(tree[rchild].r-tree[rchild].l+1)*tree[t].tag;
	tree[t].tag=0;    //复原懒标记
}
```

```CPP title:"Update"
void Update(int t,int ml,int mr,int k){    //要修改的区间[ml,mr]每个数加上k
	if(tree[t].l>=ml&&tree[t].r<=mr){    //节点代表的区间完全包含于要修改的区间
		tree[t].tag+=k;
		tree[t].sum+=(tree[t].r-tree[t].l+1)*k;
		return;
	}
	//没有被完全覆盖
	down(t);
	int mid=(tree[t].l+tree[t].r)/2;
	if(ml<=mid)    //左儿子的区间与[ml,mr]有交集
		Update(t*2,ml,mr,k);
	if(mr>=mid+1)    //右儿子的区间与[ml,mr]有交集
		Update(t*2+1,ml,mr,k);
	tree[t].sum=tree[t*2].sum+tree[t*2+1].sum;
}
```

时间复杂度$O(logN)$

# 区间查询

int Query(int t,int ql,int qr){    //从根节点开始查询，需要查询区间[ql,qr]
	if(tree[t].l>=ql&&tree[t].r<=qr){    //节点代表的区间完全包含于要查询的区间
		return tree[t].sum;
	}
	//没有被完全覆盖
	down(t);    //先下传懒标记
	int ret=0;
	int mid=(tree[t].l+tree[t].r)/2;
	if(ql<=mid){    //左儿子的区间与[ql,qr]有交集
		ret+=Query(t*2,ql,qr);
