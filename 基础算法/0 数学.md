# 排列&组合公式

## 排列公式

> 有顺序

$A^{x}_{y}$：从y开始往下乘，需要乘x项
- $A^{3}_{5}=5*4*3$
- $A^{6}_{8}=8*7*6*5*4*3$
- $A^{7}_{7}=7!$

## 组合公式

> 无顺序

$C^{x}_{y}$：分子从y开始往下乘，需要乘x项，分母从1开始往上乘，需要乘x项
- $C^{2}_{6}=6*5/1*2$
- $C^{4}_{5}=5*4*3*2/1*2*3*4$
- $C^{3}_{5}=5*3*2/1*2*3$
- 若$a+b=n$，$C^{a}_{n}=C^{b}_{n}$
- $C^{n}_{n}=C^{0}_{n}=1$

# 含n个元素的集合的子集个数

> $2^n$个子集，$2^{n-1}$个非空子集

证明：每个数有选和不选两种可能，所以有$2^n$种组合的可能

# 等比数列&等差数列

- 等差数列求和：Sn=n(a1+an)/2
- 等比数列求和：Sn=a1*(1-q^n)/(1-q)

# 曼哈顿距离

> 曼哈顿距离：dis=|x1-x2|+|y1-y2|

设两个点n1(x1,y1)和n2(x2,y2)，每个时间单位点会向四方（上下左右）扩散，则n1和n2的范围重叠需要的时间：t=dis/2+1（dis为奇数）或t=dis/2（dis为偶数）
