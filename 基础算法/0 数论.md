# 数论基础

## 整除

> $a|b$

1. $a$与$k$互素，则$a|kb\iff a|b$
2. 对$m$不为0，$a|b\iff am|bm$

## 唯一分解定理

$a=q_1^{k_1}q_2^{k_2}q_3^{k_3}...q_n^{k_n}$

其中$a$为正数，$q_i$为质数，$q_1<q_2<...<q_n$


1. 有整数：$a=\prod{q_i^{x_i}},b=\prod{q_i^{y_i}}$
则$gcd(a,b)=\prod{q_i^{min(x_i,y_i)}},lcm(a,b)=\prod{q_i^{max(x_i,y_i)}}$
多个整数仍然成立
2. $a=\prod{q_i^{x_i}},b=\prod{q_i^{y_i}}$，若$b$是$a$的因数，即$b|a$
则对任意$i$，$y_i\le x_i$
3. $a=\prod{q_i^{x_i}}$，则$a$的所有正因数个数为$(x_1+1)(x_2+1)...(x_s+1)$


### 分解质因数

```Cpp title:"暴力"
int factor[maxNum];    //质因数
int expo[maxNum];    //质因数的指数
int cnt;    //记录互异的质因数个数

void breakdown(int n){
	for(long long i=2;i*i<=n;i++){
		if(n%i==0){    //i是n的质因数
			cnt++;
			factor[cnt]=i;
			//找质因数的指数
			while(n%i==0){
				expo[cnt]++;
				n/=i;
			}
		}
	}
	if(n>1){    //最后还剩下一个质数
		cnt++;
		factor[cnt]=n;
		expo[cnt]++;
	}
}
```

时间复杂度$O(N^{1/2})$

## 欧拉函数

整数$n$由唯一分解：
$n=q_1^{k_1}q_2^{k_2}q_3^{k_3}...q_s^{k_s}$

则区间$[1,n]$中与$n$互质的数的个数$\phi(n)$：
$\phi(n)=n(1-1/p_1)(1-1/p_2)(1-1/p_3)...(1-1/p_s)$

```Cpp
int phi(int n){
	int ret=n;
	for(int i=2;i*i<=n;i++){
		if(n%i==0){
			ret*=(i-1)/i;   //即ans*=(1-1/p)
			while(n%i==0)n/=i;
		}
	}
	if(n>1){
		ret*=(n-1)/n;
	}
	return ret;
}
```

1. 积性函数：$\phi(ab)=\phi(a)\phi(b)$
2. 对于质数$p$和正数$k$：
$\phi(p^k)=p^k(1-1/p)$
3. 对于整数$n$和正数$k$：
$\phi(n^k)=n^{k-1}\phi(n)$

## 最大共约数

1. 求两个整数$(a,b)$的最大共约数：

欧几里得算法

$a,b$的公约数和$b,a\%b$的公约数相同

```Cpp title:"辗转相除法"
int gcd(int a,int b){
	int t;
	while(t){
		t=a%b;
		a=b;
		b=t;
	}
	return a;
}
```

```Cpp title:"递归"
int gcd(int a, int b) {
	if (b == 0) return a; 
	return gcd(b, a % b); 
}
```

时间复杂度$O(N)$

## 因数

> 要分别求从$1$到$n$的所有整数的因数个数

1. 遍历每个整数，再分别找因数

```Cpp
int cnt[maxNum];

for(int i=1;i<=n;i++){
	for(int j=1;j*j<=n;j++){
		if(i%j==0){
			cnt[i]++;
			if(j*j!=i)cnt[i]++;
		}
	}
}
```

时间复杂度$N^{3/2}$

2. 先遍历因数，再遍历因数和倍数的乘积

```Cpp
int cnt[maxNum];

for(int i=1;i<=n;i++){     //枚举因数
	for(int j=i;j<=n;j+=i){
		cnt[j]++;
	}
}
```

时间复杂度$O(NlogN)$，为调和级数求和

# 模逆元

对于非零整数$a,m$，若存在$b$，使得$ab\equiv1\pmod m$，则$a\pmod m$的模逆元为$b\pmod m$

## 费马小定理

设$p$是素数，对任意整数$a$且$a$不能被$p$整除，有：
$a^{p-1}\equiv1\pmod p$

利用费马小定理求逆元：

给定一个素数$m$作为模数
可推导：$aa^{m-2}\equiv1\pmod m$，则$a^{m-2}\pmod m$就是$a\pmod m$的模逆元

用**快速幂**求$a^{m-2}\pmod m$

```Cpp
int solve(int a,int mod){    //求a^(mod-2)
	int x=mod-2;
	int ret=1;
	while(x){
		if(x&1)ret=(ret*a)%mod;
		x>>=1;
		a=(a*a)%mod;
	}
	return ret;
}
```
