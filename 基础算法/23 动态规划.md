> 条件：最优子结构，重叠子问题，无后效性
> 本质是记忆化搜索

1. 确定状态：用一句话描述问题，其中涉及到的参数就是状态中的参数，即确定状态数组
2. 确定状态转移方程
3. 初始化状态数组

- 填表法：根据状态转移方程，从之前的状态推到到现在的状态
- 刷表法：用现在的状态更新之后的状态

# 线性DP

> 具有线性阶段划分，若状态有多个维度，则每个维度都是线性划分的

经典线性DP：最长上升子序列，最长公共子序列，最短编辑距离

## 最长上升子序列

- 状态：`dp[i]`表示以`a[i]`结尾的最长上升子序列长度
- 状态转移：遍历`0`~`i-1`，若`a[j]<a[i]`，`dp[i]=max(dp[i],dp[j]+1)`
- 初始化：每个状态初始化为1

最终答案不一定是`dp[n]`
时间复杂度为$O(N^2)$，更优的二分思路时间复杂度为$O(NlogN)$

### 二分思路

```Cpp
#include <iostream>  
#include <algorithm>  
  
using namespace std;  
  
int n;  
int a[100005];    //原数组  
int tail[100005];    //最长上升子序列  
int cnt;  
  
int main() {  
    cin >> n;  
    for (int i = 1; i <= n; i++) {  
       cin >> a[i];  
    }  
    for (int i = 1; i <= n; i++) {  
       if (a[i] > tail[cnt]) {  
          tail[++cnt] = a[i];  
       }  
       else {  
		  //严格上升用upper_bound，不下降用lowe_bound
          *upper_bound(tail + 1, tail + 1 + cnt, a[i]) = a[i];  
       }  
    }  
    cout << n - cnt << endl;  
    return 0;  
}
```

### Dilworth 定理

> **最小链覆盖数 = 最长反链的长度**

即将序列分割为**不上升子序列**的个数等于序列中**最长上升子序列**的长度，反过来同理

## 最长公共子序列

- 状态：`dp[i][j]`表示串`s1`的长度为`i`的前缀子串和`s2`的长度为`j`的前缀子串最长公共子序列
- 状态转移：若`s1[i]==s2[j]`说明`s1[i]`和`s2[j]`也参与到了公共子串中，`dp[i][j]=dp[i-1][j-1]+1`，若`s1[i]!=s2[j]`，说明`s1[i]`和`s2[j]`不能同时参与到公共子串中，`dp[i][j]=max(dp[i-1][j],dp[i][j-1])`，`dp[i-1][j-1]`的情况包含进了这两种情况中
- 初始化：子串长度为0公共子串长度也为0，`i`为0的每个状态初始化为0，`j`为0的每个状态初始化为0

## 最短编辑能力

- 状态：`dp[i][j]`表示串`s1`的长度为`i`的前缀子串要经过编辑变为`s2`的长度为`j`的前缀子串所需要的最小步骤
- 状态转移：若`s1[i]==s2[j]`，不需要任何操作`dp[i][j]=dp[i-1][j-1]`，若`s1[i]!=s[j]`，有三种操作（删除，插入，修改）
	- 删除：`s1`为`xxxxab`，`s2`为`xxxxa`，把`b`删了
	 将`s1`的长度为`i-1`的前缀子串变为`s2`长度为`j`的子串的操作数再加上一次删除操作，`dp[i-1][j]+1`
	- 插入：`s1`为`xxxx`，`s2`为`xxxxa`，插入一个`a`
	 将`s1`的长度为`i`的前缀子串变为`s2`长度为`j-1`的子串的操作数再加上一次插入操作，`dp[i][j-1]+1`
	- 修改：`s1`为`xxxxa`，`s2`为`xxxxb`，修改`a`为`b`
	 将`s1`的长度为`i-1`的前缀子串变为`s2`长度为`j-1`的子串的操作数再加上一次修改操作，`dp[i-1][j-1]+1`
	`dp[i][j]=min(min(dp[i-1][j]+1,dp[i][j-1]+1),dp[i-1][j-1]+1)`
- 初始化：当`j`为0时，`s1`的子串最少需要执行`i`次删除操作，当`i`为0时，`s1`的子串最少需要执行`j`次插入操作

# 区间DP

> 对区间的动态规划，把区间划分为若干个子区间

对于一个区间，划分方式不止一种，需要枚举所有划分方式（找区间的分割点），找到最优的划分方式

由于长区间由端区间转移得到，所以先处理短区间

`dp[i][j]`表示区间i~j的最优解

```Cpp
for(int len=2;len<=n;len++){    //枚举区间长度
	for(int i=1;i+len-1<=n;i++){    //枚举左端点
		int j=i+len-1;    //右端点
		for(int k=i;k<j;k++){    //枚举分割点
			//cost为合并区间的消耗
			dp[i][j]=min(dp[i][j],dp[i][k]+dp[k+1][j]+cost);
		}
	}
}
```

时间复杂度$O(N^3)$

## 枚举区间的方式

1. 枚举区间长度和左边界

```Cpp
for(int len=1;len<=n;len++){    //枚举区间长度
	for(int i=1;i+len-1<=n;i++){    //枚举左边界
		solve();
	}
}
```

2. 枚举左边界和右边界

```Cpp
for(int l=1;l<=n;l++){
	for(int r=l;r<=n;r++){
		solve();
	}
}
```

3. 枚举区间的**中间点**，然后区间向左右扩张，区间扩张的过程中可以进行状态转移

```Cpp
for (int i = 1; i <= n; i++) {    //枚举中间点
	//区间长度为奇数
	int l = i, r = i;
	while (l >= 1 && r <= n) {    //向左右扩张
		solve();
		l--, r++;
	}
	if (i == n)break;
	//区间长度为偶数
	l = i, r = i + 1;
	while (l >= 1 && r <= n) {    //向左右扩张
		solve();
		l--, r++;
	}
}
```

# 背包问题

> 给定一组价值和容量确定的物品，限定总容量的前提下如何选择是最终的总价值最高

有n种物品，每个物品的价值为`v[i]`，容量（重量）为`w[i]`，给定容量`c`的背包，找到背包能装下的最大总价值

## 01背包

> 每种物品只能选一次

- 状态：`dp[i][j]`表示目前正在讨论第`i`个物品（前i个物品任选），目前剩余背包容量
- 状态转移：
	- 若第`i`个物品不选，`dp[i][j]=dp[i-1][j]`
	- 若第`i`个物品要选，且`j-w[i]>=0`，`dp[i][j]=dp[i-1][j-w[i]]+v[i]`
	`dp[i][j]=max(dp[i-1][j],dp[i][j-w[i]]+v[i])`
- 初始化：`dp[i][0]=0,dp[0][j]=0`

```Cpp
int bag01(){
	for(int i=1;i<=n;i++){
		for(int j=1;j<=c;j++){
			if(j-w[i]>=0){
				dp[i][j]=max(dp[i-1][j],dp[i-1][j-w[i]]+v[i]);
			}
			else dp[i][j]=dp[i-1][j];
		}
	}
	return dp[n][c];
}
```

空间优化：一维滚动数组`dp[i]`

枚举`j`需要从后往前更新，若从前往后更新，计算后面的`dp`可能需要用到上一层的前面的`dp`值，但是从前往后更新把前面的上一层的值覆写了，得到的`dp`值是这一层表示的物品多次放入了的结果（完全背包）

```Cpp
int bag01(){
	for(int i=1;i<=n;i++){
		for(int j=c;j>=w[i];j--){    //从后往前更新
			dp[j]=max(dp[j],dp[j-w[i]]+v[i]);
		}
	}
	return dp[c];
}
```

求可能性问题：

`dp[j]`表示考虑前`i`个物品，能否构成总容量为`j`
```Cpp
for (int i = 1; i <= n; i++) {    //枚举每个物品  
    for (int j = m; j >= w[i]; j--) {     //枚举容量
       dp[j] = dp[j] | dp[j - w[i]];  
    }  
}
```

## 完全背包

> 每种物品可以选无数次

```Cpp
int CompletedBag(){
	for(int i=1;i<=n;i++){
		for(int j=1;j<=c;j++){    //从前往后更新
			dp[i][j]=dp[i-1][j];    //一个也不放
			for(int k=1;k<=j/w[i];k++){    //枚举要放k个i物品
				dp[i][j]=max(dp[i][j],dp[i-1][j-k*w[i]]+k*v[i]);
			}
		}
	}
	return dp[n][c];
}
```

空间&时间优化：一维滚动数组

枚举`j`需要从前往后枚举

```Cpp
int CompletedBag(){
	for(int i=1;i<=n;i++){
		for(int j=w[i];j<=c;j++){    //从前往后更新
			dp[j]=max(dp[j],dp[j-w[i]]+v[i]);
		}
	}
	return dp[c];
}
```

求完全背包的方案数：
```Cpp title:"方案数"
dp[0]=1;

for(int i=1;i<=n;i++){    //枚举物品
	for(int j=w[i];j<=c;j++){    //枚举容量
		dp[j]+=dp[j-w[i]];    //方案数转移
	}
}
```

## 分组背包

> 枚举顺序：组->背包容量->每组中的物品

`dp[i][j]`表示考虑前`i`组，容量为`j`时的最优解

转移：`dp[i-1][j]`表示当前组不放，如果要放，枚举每组中的物品`dp[i-1][j-w[p]]+v[p]`表示要放`i`组中重量为`w[i]`，价值为`v[i]`的物品

压缩空间：`dp[j]`

```Cpp
for (int t = 1; t <= k; t++) {    //遍历每组  
    for (int i = m; i >= 0; i--) {      //遍历容量
       for (auto p: group[t])      //遍历组中的物品
          if (i >= w[p])  
             dp[i] = max(dp[i], dp[i - w[p]] + v[p]);  
    }  
}
```

# 树形DP

> 用树存储，在树上进行状态转移
> 用记忆化搜索实现

把一个节点或一颗子树看作一个状态，状态转移在父子节点间，兄弟节点间，树和子树间

搜索方式：
1. 叶到根：从根节点往下搜索，回溯时更新信息
2. 根到叶：先从根节点往下搜索进行预处理，再从根节点往下搜索更新答案

## 选择节点问题

相邻节点（父子）不能同时存在，要求最大值或最小值

- 状态：`dp[x][1]`表示节点`x`要选时的最优解，`dp[x][0]`表示节点`x`不选时的最优解
- 状态转移：`dp[x][0]<--dp[a][0],dp[a][1]`，`dp[x][1]<--dp[a][0]`，`a`为`x`的儿子

## 树上背包问题

状态：`dp[x][i][j]`表示以`x`为根节点，考虑前`i`棵子树，不超过`j`容量时的最优解，可以压缩为`dp[x][j]`

# 状态压缩DP

> 利用计算机的二进制位表示状态，一个bit位可以表示两种状态

用一个数表示多个事件/物品组合的某一状态，其中这个数的二进制的某一位代表某个事件/物品的状态（1或0）

缩小了储存空间，利用二进制的位运算进行状态转移

状压DP是一种暴力的算法，时间复杂度为指数级

类型一般为：棋盘类问题， 集合类问题，初始状态到最终状态的最短路问题

## 位运算

`&`与，`|`或，`^`异或，`~`取反，`<<`左移（右边补0），`>>`右移（左边补符号位）

规律：（x为1或0）
- 1&x=x
- 0&x=0
- 1|x=1
- 0|x=x

1. 判断数`x`的第`i`位是否为1：`if((1<<(i-1))&x>0)`
2. 将数`x`的第`i`位改为1：`x|=(1<<(i-1))`
3. 将数`x`的第`i`位改为0：`x&=~(1<<(i-1))`
4. 将数`x`最右边的1改为0：`x&=(x-1)`
5. 枚举状压集合`S`的子集`S1`和补集`S2`：
	```Cpp
	for(int s1=s;s1!=0;s1=(s1-1)&s){    //(s1-1)&s得到仅次于s1的最大的子集
		s2=s^s1;    //s2为s1的补集
	}
	```
