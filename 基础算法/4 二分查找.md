> 常用于找最值，最小化最大值，最大化最小值，优化枚举，一般对答案区间二分

二分前提：单调

- 在树上二分需要维护一个**栈**，在栈上进行二分

# 模板

```Cpp
int l=min_,r=max_;
int ans;
while(l<=r){
	int mid=(l+r)/2;
	if(judge(mid)){
		ans=mid;
		l=mid+1;    //r=mid-1
	}
	else r=mid-1;    //l=mid+1
}
```

# C++中的lower_bound和upper_bound

> 头文件\<algorithm>
> 内部实现：二分

- 前提：有序序列
- lower_bound：找到序列中第一个大于或等于x的数的迭代器
- upper_bound：找到序列中第一个大于x的数的迭代器
- 没找到返回末尾迭代器end()

**应用**：
求有序序列中等于x的数的个数
`int num=upper_bound(v.begin(),v.end(),x)-lower_bound(v.begin,v.end(),x);`
