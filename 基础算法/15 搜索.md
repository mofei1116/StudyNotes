> 搜索是暴力的一种手段

1. 常用到`visited[]`数组记录搜索过程中访问过的节点，避免**重复搜索**
2. 对于**网格**的搜索常考虑4或8个方向的搜索
3. 别忘了判越界
4. 有时需要特判起点和终点一样的情况

# DFS深度优先搜索

利用递归实现，通常构造搜索树

有时需要**回溯**，即恢复回退到上一层递归后恢复递归前的状态，比如：
```Cpp
void dfs(int x){
	//......
	visited[x]=true;
	dfs(x+1);
	visited[x]=false;
	//......
}
```

## DFS的优化

> 本质是减少对**不合法**答案和**重复**答案的枚举，统称为**剪枝**

- 可行性剪枝：在进入递归过程第一步判断当前答案是否已经不合法，不合法直接返回
- 记忆化搜索：用数组记录已经遍历过的状态的信息，重复搜索时直接读表返回，不需要再往下递归

# BFS广度优先搜索

利用队列实现，可以用于求**单源无权图**的最短路

- 有时需要在队列节点中包含时间，状态，走过的路程等数据
- 有时需要`dis`数组记录目前走过的步数/距离，以找到合法位置时输出最优解，用-1或infi初始化`dis`数组
- 广搜不一定是以一个点为起点，可以以一块或多块区域为起点，作为起点的区域的`dis`初始为0
