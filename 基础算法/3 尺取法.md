> 滑动窗口/双指针法
> 常用于求有一定限制的区间个数或满足限制的最短区间

指针`l`表示窗口左端，`r`表示窗口右端，枚举`r`，再枚举`l`直到合法为止，然后再枚举`r`，循环，时间复杂度O(N)

- 条件：区间权值会随区间长度线性变化（序列内每个元素都是非负数或非正数）
- 优点：不会枚举一定不合法和合法但是一定不是答案的区间
- 内循环枚举`l`是从非法枚举直到合法或是从合法枚举直到非法看具体情况
- 若外循环要枚举`l`的话，需要`l`从右边界往左枚举，内循环枚举`r`

```Cpp
while(r<=n){
	add(r);    //区间权值增加
	while(l<=r&&!isValid(sum)){    //l左移
		sub(l);    //区间权值减小
		l++;
	}
	r++;
}
```
