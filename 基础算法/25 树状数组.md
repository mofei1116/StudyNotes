> 实现单点修改和区间查询

树状数组能解决的问题，线段树也能解决，但是线段树空间复杂度较高，代码长
树状数组空间复杂度为$O(N)$，时间复杂度为$O(logN)$

树状数组维护的区间信息需要满足结合律，可差分（具有逆运算），所以不能维护区间最大值

用树状数组维护原数组的差分数组，可以实现区间修改和单点查询，时间复杂度$O(logN)$
若用普通数组维护差分数组，单点查询时间复杂度为$O(N)$

树中的节点个数为原数组中的元素个数

底层以上的元素下落到最底层的空位：

将树中的所有节点都放在最底层的数组中，构成树状数组，利用树状数组进行单点修改和区间查询，时间复杂度为$O(logN)$，若$N=2^k$，则树状数组表示一棵树，否则表示森林

## 每个元素对应的区间

![[Pasted image 20260426141615.png]]

规律：树状数组下标`x`表示的区间的右边界为`x`，区间长度为`x`的二进制表示中最低位的1和后面的0表示的十进制数（lowbit(x)），所以下标`x`表示的区间的为`[x-lowbit[x]+1,x]`
父节点下标为`x+lowbit(x)`，左兄弟下标为`x-lowbit(x)`（若没有兄弟，认为是父节点的左兄弟）

## 求lowbit

```Cpp
int lowbit(int x){
	return x&(~x+1);
}
```
对一个数的补码取反加一得到的是其相反数的补码

```Cpp
int lowbit(int x){
	return x&(-x);
}
```

# 单点修改

先找到包含第`x`个数据的最小区间（`t[x]`），再从这个区间开始往父节点修改，直到修改到根节点

```Cpp
void Update(int x,int k){
	for(int i=x;i<=n;i+=lowbit(i)){
		t[i]+=k;
	}
}
```

单点修改时间复杂度$O(logN)$

# 建树

建树过程可以认为是单点修改，原来的树中全是0，将原数组中的数加到树状数组中去，建树时间复杂度$(NlogN)$

# 区间查询

要求从下标1到下标x的前缀和

```Cpp
int Query(int x){
	int sum=0;
	for(int i=x;i>=1;i-=lowbit(i)){
		sum+=t[i];
	}
	return sum;
}
```

时间复杂度$O(logN)$

要求任意区间用两个前缀和相减得到：`Query(r)-Query(l-1)`
