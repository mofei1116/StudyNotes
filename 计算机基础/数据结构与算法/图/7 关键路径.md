> AOE网（Activity On Edge）：边表示活动，节点表示入度边活动的结束，出度边活动的开始

**关键路径**就是这条路径延误会导致整个工程延误的路径，关键路径可能不止一条，若图中含有环，则工程永远无法完成

- 源点：入度为0的点
- 汇点：出度为0的点
- ETV（Earliest Time of Vertex）：事件最早完成（开始）时间，从源点开始往后按拓扑序列推，取最大值
- LTV（Latest Time of Vertex）：事件最晚完成（开始）时间，从汇点开始往前逆拓扑序列推，取最小值
- 关键活动：没有机动时间
- 关键路径：由关键活动组成的最长的序列
- 图中的边的weight就代表活动持续时间
- 关键路径中的汇点的最大的ETV就是这个有向带权无环图的**最长路径**

# 计算ETV

假设用一个数组`ETV`存每个顶点代表的最早开始（完成）时间，用一个入度数组`indegree`存每个顶点的入度个数，按照**拓扑排序**，每次从暂存区中取一个入度为0的顶点
- 检查这个顶点的所有出度顶点
- 出度顶点的indegree减一，若减一后入度为0，将这个出度顶点入暂存区
- 若这个顶点的ETV加上出度边代表的活动持续时间**大于**出度顶点的ETV，将出度顶点的ETV更新为弧尾顶点的ETV加上弧的持续时间（因为目的是找最大值），采用**动态更新**出度顶点的ETV的方法，就不用每次都在入度找最大值来确定ETV

由于计算ETL需要正序的拓扑排序，LTV需要倒序的拓扑排序，所以计算ETV的时候可以用一个堆栈`outcome`把拓扑排序的结果存起来，计算LTV的时候只需要一个个出栈得到的就是倒序的拓扑排序

```Cpp
int ETV[MaxNum];

int indegree[MaxNum];

stack<int> outcome;    //拓扑排序结果

bool getLTV(LGraph* graph,stack<int>& outcome){
	initIndegree(indegree);    //初始化入度数组
	for(int i=0;i<graph->vertexNum;i++){
		ETV[i]=startTime;    //每个ETV初始化为工程开始时间
	}
	stack<int> s;    //暂存区
	//将初始入度为0的点入栈
	for(int i=0;i<graph->vertexNum;i++){
		if(indegree[i]==0){
			s.push(i);
		}
	}
	int k;
	Edge* p;
	int count=0;
	while(!s.empty()){
		count++;
		k=s.top();
		outcome.push_back(k);
		s.pop();
		p=graph->nodes[k].firstEdge;
		while(p){
			indegree[p->id]--;
			if(indegree[p->id]==0)s.push(p->id);
			if(ETV[k]+p->weight>ETV[p->id])
				ETV[p->id]=ETV[k]+p->weight;
			p=p->next;
		}
	}
	return count==graph->vertexNum;     //返回是否有环
}
```

# 计算LTV

计算ETV的时候已经得到了拓扑排序的结果，计算LTV时只需要访问栈顶然后出栈，每次访问栈顶节点，需要检查这个节点的所有出度，找出出度顶点的LTV减去出度持续时间的**最小值**，更新这个点的LTV

传入整个工程的最晚完成时间为`endTime`

```Cpp
int LTV[MaxNum];

void getLTV(LGraph* graph,stack<int>& outcome,int endTime){
	for(int i=0;i<graph->vertexNum;i++){
		LTV[i]=endTime;    //初始化每个LTV为工程结束时间
	}
	int k;
	Edge* p;
	while(!outcome.empty()){
		k=outcome.top();
		outcome.pop();
		p=graph->nodes[k].firstEdge;
		while(p){   //检查所有出度
			if(LTV[p->id]-p->weight<LTV[k]){
				LTV[K]=LTV[p->id]-p->weight;
			}
			p=p->next;
		}
	}
}
```

# 找关键事件

一个事件的实际持续时间（理论持续时间+冗余时间）可能比理论持续事件长，最大实际持续时间（最晚完成时间-最早开始时间）与理论持续时间相等的事件是关键事件，即没有冗余时间

```Cpp
int ETV[MaxNum];
int indegree[MaxNum];
stack<int> outcome;
int LTV[MaxNum];

bool getKeyPath(){
	//计算最早完成时间
	if(!getETV(graph,indegree,ETV,outcome))return false;  //若存在环则返回false
	//计算最晚完成时间
	getLTV(graph,outcome,LTV);
	//找关键事件，需要遍历所有边
	Edge* p;
	for(int i=0;i<graph->vertexNum;i++){
		p=graph->nodes[i].firstEdge;
		while(p){
			if(LTV[p->id]-ETV[i]==p->weight){
				visit(i,p);    //访问行为
			}
			p=p->next;
		}
	}
	return true;
}
```
