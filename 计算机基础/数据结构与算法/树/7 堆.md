# 结构

在**完全二叉树**的基础上，树中每个节点的key值都大于（最大堆）或小于（最小堆）其非空左右子树

# 插入

1. 数据插入到堆结构的最后
2. 向上过滤，直到满足堆的条件

```Cpp
int a[maxNum];
int n;    //数据个数

void InsertHeap(KeyType key){    //插入最大堆
	a[++n]=key;    //插在最后
	//向上过滤
	for(int i=n;i>1;i/=2){
		if(a[i/2]<a[i])    //和父节点比较
			swap(a[i/2],a[i]);
		else break;
	}
}
```

一次插入时间复杂度$O(logN)$，$N$为当前节点个数

# 删除

> 只能删堆顶

1. 堆顶节点和堆的最后一个节点交换数据
2. 删除堆的最后一个节点
3. 从堆顶开始向下过滤

```Cpp
int a[maxNum];

int DeleteHeap(int n){    //从最大堆删
	int ret=a[1];
	swap(a[1],a[n]);
	downAdjust(1);
	return ret;
}

void downAdjust(int t){
	int child;
	int i;
	for(i=t;2*i<=n;i=child){
		child=2*i;   //先指向左孩子
		if(child+1<=n&&a[child]<a[child+1]){//找较大的儿子
			child++;
		}
		if(a[i]<a[child]){
			swap(a[i],a[child]);
		}
		else break;
	}
}
```

# 建堆

## 向上过滤

执行$n$次插入，每次插入都要向上过滤

看成高度为$h$的满二叉树，第$k$层有$2^{k-1}$个节点，每个节点向上过滤的时间复杂度为$k-1$，总的时间复杂度为$\sum^{h}_{1}(2^{k-1})(k-1)$，等差乘等比错位相减

时间复杂度为$O(NlogN)$

## 向下过滤

先把所有节点放在数组中，最后再一次性调整

调整堆有个前提是左右子树都得是堆，所以从最后一个有儿子的节点（$n/2$）开始调整，调整的策略也是**向下过滤**，以这个节点为根节点的堆调整好了后调整数组中的上一个节点，直到调整完整个堆的根节点

```Cpp
int a[maxNum];

void buildHeap(int n){    //建最大堆
	for(int i=n/2;i>=1;i--){    //枚举要调整的子树的根节点
		downAdjust(i);
	}
}

void downAdjust(int t){    //根节点
	int child;
	int i;
	for(i=t;2*i<=n;i=child){
		child=2*i;   //先指向左孩子
		if(child+1<=n&&a[child]<a[child+1]){//找较大的儿子
			child++;
		}
		if(a[i]<a[child]){
			swap(a[i],a[child]);
		}
		else break;
	}
}
```

看成高度为$h$的满二叉树，第$k$层有$2^{k-1}$个节点，每个节点向下过滤的时间复杂度为$h-k+1$，总的时间复杂度为$\sum^{h}_{1}(2^{k-1})(h-k+1)$，等差乘等比错位相减

时间复杂度$O(N)$
