# 基本概念

- 树的路径长度：叶子节点的路径长度之和
- 加权路径长度：设每个叶子节点都带有**权值**，从根节点到这个叶节点的路径长度与权值的乘积就是加权路径长度
- 树的加权路径长度（WPL）：叶节点的加权路径长度之和
- 哈夫曼树就是加权路径长度（WPL）最小的树
- 对于一颗Huffman树，只有度为0和度为2的节点，由于n0=n2+1且n0+n1+n2=总结点个数，其中n1=0，所以总结点个数为2* n0-1

# 哈夫曼编码

> 通过哈夫曼树构造的编码是最优编码（加权路劲长度之和最小），但最优编码不一定是通过哈夫曼树构造的

- 定长编码：每个字符使用的二进制长度相等，比如ASCll码（8bit），Unicode码（16bit）
- 变长编码：根据字符出现频率调整字符编码长度，出现频率高编码短，需要满足前缀属性

把树中的**边**作为编码中的0或1，一般左0右1，叶节点的权值为字符出现的频度，从根节点到叶节点的**路径**就是这个叶节点代表的字符的编码

把字符放在叶节点上是为了避免出现**前缀码**，若某个字符A不在叶节点上，则存在另一个在叶节点上的字符B的路径经过这个节点，所以A的路径是B的路径的前部分，就是说A是B的前缀码

# 哈夫曼树的构造

## 思路

> 贪心

为了让权值大的尽量离根节点近，权值小的离根节点远

最开始已经有了n个独立的子树（n个需要编码的字符），从没有父节点的子树中选择权值最小的两个节点，增加新的节点作为这两个节点的根节点，其权值为两个子树根节点的权值之和，再重复构造新的子树，直到只有一个没有父亲的节点，这个节点就是Huffman树的根节点，由于权值小的先合并，所以权值小的合并次数可能更多，所以祖先更多，离根节点更远

由于需要合并n-1次，所以还需要增加n-1个节点，最终总节点数为2n-1


## 结构

一个数据域weight，三个指针域parent，lchild，rchild，分别表示父节点的下标，左儿子的下标，右儿子的下标

```Cpp
struct TreeNode{
	int weight;
	int parent,left,right;
}
TreeNode nodes[M];    //开2n个
```

## 实现

```Cpp
void getMin(TreeNode* nods,int& m1,int& m2,int p){    //遍历
	int wei1,wei2;    //最小weight和次小weight
	int i;
	for(i=1;i<p;i++){    //找到第一个没有parent的节点用来初始化
		if(nods[i].parent==0){
			m1=m2=i;
			wei1=wei2=nods[i].weight;
			break;
		}
	}
	int j;
	for(j=i;j<p;j++){
		if(nods[j].parent==0){
			if(nods[j].weight<wei1){    //最小值变成次小值
				wei2=wei1;
				m2=m1;
				wei1=nodes[j].weight;   //更新最小值
				m1=j;
			}
			else if(nodes[j].weight<wei2){
				wei2=nods[j].weight;    //更新次小值
				m2=j;
			}
		}
	}
}

TreeNode* BuildHuffmanTree(int n){
	int m=2*n-1;
	TreeNode* nodes=new TreeNode[2*n];   //开数组
	int i;
	//初始化
	for(i=1;i<=m;i++){
		nodes[i].parent=nodes[i].left=nods[i].right=nodes[i].weight=0;
	}
	for(i=1;i<=n;i++){    //填入叶节点
		cin>>nodes[i].weight;
	}
	//填入剩下的节点
	for(i=n+1;i<=m;i++){
		int m1,m2;    //前面符合条件的最小的两个节点的下标
		getMin(TreeNode* nods,m1,m2,i);
		nods[m1].parent=nodes[m2].parent=i;
		nods[i].left=m1;
		nods[i].right=m2;
		nods[i].weight=nods[m1].weight+nodes[m2].weight;
	}
	return nodes;
}
```

## 构造Huffman编码

由于表示字符的节点在叶子上，从下往上走到根节点得到相反的编码顺序

思路一：用stack储存遍历的结果，再把stack一个一个pop出来就是正确的顺序了

思路二：
用一个`temp`数组来储存正确的顺序，从后往前填值（字符），Huffman树的最大高度为n，所以最长的编码长度为n，所以`temp`数组可以开成n的长度
`start`指针表示编码开始的第一个字符在`temp`中的下标，初始化为最后一个下标n-1，初始start的位置设为'\0'，然后从叶子节点往上遍历，依次填到`temp`中`start`的位置上，每次填值前`start`减一

若遍历中某个节点是其后驱的左儿子，就填0，右儿子就填1

```Cpp
char* gerHuffmanCodes(int p,TreeNode* nods,int n){  //p是叶子在nodes中的下标
	char* temp=new char[n];
	int start=n-1;
	temp[start]='\0';
	int parent;    //下标为i的节点的父亲的下标
	while(p!=0){    //遍历到根节点
		parent=nods[p].parent;
		if(nods[par].lchild==p){
			temp[--start]='0';
		}
		else temp[--start]='1';
		p=parent;
	}
	char* ret=new char[n-start];
	strcpy(ret,&temp[start]);
	return ret;
}
```
