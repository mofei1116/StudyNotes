> 只允许在一端插入，在另一端删除
> 先进先出，后进后出

- 队首：执行出队操作
- 队尾：执行入队操作

# 顺序存储

> `front`记录队首在数组中的下标，`rear`记录队尾在数组中的下标

- 初始化：`front=0,rear=-1`
- 判空：`if(rear<front)`
- 判满：`if(rear==max-1)`
- 入队：先判满，`q[++rear]=key`
- 出队：先判空，`front++`

## 循环队列

> 首位相接，基于循环数组

- 对下标**取模**，mod等于数组长度
- 循环队列中`rear`指向队尾的下一个位置
- 初始化：`front=rear=0`
- 判空：`if(rear==front)`
- 判满：`if((rear+1)%max==front)`，数组只存`max-1`个数据
- 入队：先判满，`queue[rear]=key,rear=(rear+1)%max`
- 出队：先判空，`front=(front+1)%max`

# 链式存储

> 队首在首元节点一侧，队尾在尾节点一侧

- 初始化：队尾指针`rear`和队首指针指向头节点
- 判空：`if(rear==head)`
- 入队：尾插
- 出队：先判空，头插

# 双端队列

> 两端都可以入队出队，但是只能访问两端，无法遍历

若规定从左端入队的数据只能从左端出队，从右端入队只能从右端出队，则该双端队列是两个栈底相连的栈，栈顶就是双端队列的两端

## 顺序存储

> 基于循环链表实现

- `sum`记录数据个数，初始化为0
- 出队前先判空，入队前先判满
- 判空：`if(!sum)`
- 判满：`if(sum==max)`
- 左端入队：`l=(l-1+max)%max;data[l]=key;`
- 右端入队：`r=(r+1)%max;data[r]=key;`
- 左端出队：`l=(l+1)%max`
- 右端出队：`r=(r-1+max)%max`

## 链式存储

> 基于双向链表实现

- `sum`记录数据个数，初始化为0
- `l`指向最左端的节点，`r`指向最右端的节点
- 出队前先判空
- 判空：`if(!sum)`
- 左端出队：
```Cpp
	if(l->next){
		l=l->next;
		delete l->pre;
		l->pre=nullptr;
	}
	else delete l;
	sum--;
```
- 右端出队：
```Cpp
	if(r->pre){
		r=r->pre;
		delete r->next;
		r->next=nullptr;
	}
	else delete r;
	sum--;
```
- 左端入队：
```Cpp
	new node;
	node->data=key;
	node->next=node->pre=nullptr;
	if(!sum)l=r=node;
	else {
		l->pre=node;
		node->next=l;
	}
```
- 右端入队：
```Cpp
	new node;
	node->data=key;
	node->next=node->pre=nullptr;
	if(!sum)l=r=node;
	else{
		r->next=node;
		node->pre=r;
	}
```
