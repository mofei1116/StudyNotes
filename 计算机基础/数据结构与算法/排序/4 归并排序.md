# 归并

> 将两个有序序列合并为一个有序序列

1. 两个指针`i`和`j`分别指向两个序列的第一个数
2. 比较两个指针对应的两个数，若`a[i]<=b[j]`，`a[i]`放到结果序列中，`i`后移，
若`a[i]>b[j]`，`b[j]`放到结果序列中，`j`后移
3. 最后把两个序列中有剩下的一个序列剩下的数放到结果序列中

```Cpp title:"归并"
int a[maxNum];
int sizeA;
int b[maxNuj];
int sizeB;
int result[maxNum];
int cnt;

void Merge(){
	int i=1,j=1;
	while(i<=sizeA&&j<=sizeB){
		if(a[i]<=b[i]){
			result[++cnt]=a[i++];
		}
		else result[++cnt]=b[j++];
	}
	//下面两个循环只会执行其中一个
	while(i<=sizeA)result[++cnt]=a[i++];
	while(j<=sizeB)result[++cnt]=b[j++];
}
```

# 归并排序

1. 将区间分为两块，递归处理左右子区间，使左右子区间有序
2. 将左右子区间归并

```Cpp
int a[maxNum];
int temp[maxNum];

void MergeSort(int l,int r){    //初始调用为1,n
	if(l>=r)return;    //不需要排序
	int mid=(l+r)/2;
	MergeSort(l,mid);
	MergeSort(mid+1,r);
	int cnt=0;    //记录temp中数据个数
	int i=l,j=mid+1;
	while(i<=mid&&j<=r){
		if(a[i]<=a[j])temp[++cnt]=a[i++];
		else temp[++cnt]=a[j++];
	}
	while(i<=mid)temp[++cnt]=a[i++];
	while(j<=r)temp[++cnt]=a[j++];
	//把temp中的数据填到原数组中
	for(int i=1;i<=cnt;i++){
		a[l+i-1]=temp[i];
	}
}
```

时间复杂度$O(NlogN)$，非就地排序，空间复杂度$O(N)$，稳定
