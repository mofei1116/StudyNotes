# 计数排序

统计每个数出现的个数，按数量输出

```Cpp
int a[maxNum];
int cnt[M];
int result[maxNm];    //结果数组
int p;

void countSort(int n){
	int mi=a[1],ma=a[1];
	for(int i=1;i<=n;i++){
		mi=min(mi,a[i]);
		ma=max(ma,a[i]);
		cnt[a[i]]++;
	}
	for(int i=mi;i<=ma;i++){
		for(int j=1;j<=cnt[i];j++){
			result[++p]=i;
		}
	}
}
```

时间复杂度$O(N+M)$（$M$是最大值），非就地排序，空间复杂度$O(M)$，不稳定

为了使其稳定，用`cnt`的前缀和数组`sum`，`sum[a[i]]`表示最后一个数`a[i]`排在第`sum[a[i]]`个位置，从后往前遍历原数组，填了一个数后`sum[a[i]]--`，此时的`sum[a[i]]`表示倒数第二个`a[i]`的位置

```Cpp title:"稳定优化"
int a[maxNum];
int cnt[M];
int result[maxNm];    //结果数组

void countSort(int n){
	int mi=a[1],ma=a[1];
	for(int i=1;i<=n;i++){
		mi=min(mi,a[i]);
		ma=max(ma,a[i]);
		cnt[a[i]]++;
	}
	//构造前缀和数组
	sum[mi]=cnt[mi];
	for(int i=mi+1;i<=ma;i++){
		sum[i]=sum[i-1]+cnt[i];
	}
	//从后往前遍历原数组，把数据放在对应的位置上
	for(int i=n;i>=1;i--){
		result[sum[a[i]]]=a[i];
		sum[a[i]]--;
	}
}
```

时间复杂度$O(N+M)$（$M$是最大值），非就地排序，空间复杂度$O(M)$，稳定

# 桶排序

> 适合分布比较均匀的数据

将$n$个数据分为若干组（桶），使得桶间有序，桶内乱序，再对桶内单独排序

# 基数排序

> 基于计数排序

对所有数据补成相同位数，高位补0，先对低位计数排序，再对高位计数排序

时间复杂度$O(k(N+10))$（$k$为最高位数）,非就地排序，空间复杂度$O(10)$，稳定
