> 都是基于选择的排序

# 选择排序

每次在乱序区中找到一个最小值，放到乱序区第一个位置，执行$n-1$次选择排序

```Cpp
int a[maxNum];

void selectSort(int n){
	for(int i=1;i<=n-1;i++){    //枚举乱序区左端点
		int k=i;
		//找最小值
		for(int j=i;j<=n;j++){
			if(a[j]<a[k]){
				k=j;
			}
		}
		//交换两数
		int t=a[i];
		a[i]=a[k];
		a[k]=t;
	}
}
```

时间复杂度$O(N^2)$，就地算法，空间复杂度$O(1)$，不稳定

# 堆排序

将乱序区维护成大顶堆，每次选择找乱序区的最大值（堆顶）放在乱序区最后，保证堆顶一直在下标1位置

[[7 堆|堆]]

1. 先对整个数组建堆（向下过滤）
2. 执行$n-1$轮排序，选择堆顶（最大值）和乱序区最后一个数交换，堆的大小-1，堆顶向下调整，维护大顶堆

```Cpp
int a[maxNum];

void heapSort(int n){
	buildHeap(n);    //对n个数据建大顶堆
	int size=n;    //堆的大小
	for(int i=n;i>1;i--){    //枚举乱序区右端点
		swap(a[1],a[i]);    //堆顶（最大值）放在乱序区最后
		size--;
		downAdjust(1);    //向下过滤
	}
}
```

建堆时间复杂度$O(N)$，调整总的时间复杂度为$O(NlogN)$

时间复杂度$O(NlogN)$，就地排序，空间复杂度$O(1)$，不稳定
