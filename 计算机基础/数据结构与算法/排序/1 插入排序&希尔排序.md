# 直接插入排序

## 实现

一开始$[1,1]$是有序区，$[2,n]$是无序区，需要进行$n-1$次插入排序

每次插入排序：
1. 设无序区第一个数是`x`，倒着遍历有序区，找到第一个小于等于`x`的位置`j`，`x`应该插入到`j+1`位置
2. 将从`j+1`开始的有序区往后挪动一，空出`j+1`的位置
3. 将`x`赋给`j+1`位置，完成一次插入后，有序区长度+1，无序区长度-1

```Cpp title:"直观代码"
int a[maxNum];

void insertSort(int n){
	for(int i=1;i<=n-1;i++){    //枚举有序区右边界
		int x=a[i+1];
		int j;
		for(j=i;j>=1;j--){
			if(a[j]<=x)break;
		}
		for(int k=i;k>=j+1;k--){
			a[k+1]=a[k];
		}
		a[j+1]=x;
	}
}
```

```Cpp title:"优化代码"
int a[maxNum];

void insertSort(int n){
	for(int i=1;i<=n-1;i++){    //枚举有序区右边界
		int x=a[i+1];
		int j;
		for(j=i;j>=1;j--){    //边找边挪
			if(a[j]<=x)break;
			a[j+1]=a[j];
		}
		a[j+1]=x;
	}
}
```

最坏时间复杂度$O(N^2)$，最好时间复杂度$O(N)$，平均时间复杂度$O(N^2)$，空间复杂度$O(1)$，就地排序，稳定

## 优化

### 折半查找

在有序区中找第一个小于等于`x`的数可以用**二分**，但时间复杂度没有太大优化

### 二路插入排序

用循环数组存数据，时间复杂度没有太大优化，空间复杂度为$O(N)$

# 希尔排序

> 增量序列取shell序列的缩小增量排序

## 实现

直接插入排序数据量越小越快，整体越有序越快

先将待排序的数据分组，每组单独进行直接插入排序（实现时一起交叉着排序），使整体基本有序，最后再对整体执行一次直接插入排序

每一次分组：

将数据分为`d`组，每组$n/d$个数据，`d`也是下标增量，第一次分组`d=n/2`
第一组：$a[1],a[1+d],a[1+2d]...$
第二组：$a[2],a[2+d],a[2+2d]...$
以此类推

下一次分组`d/=2`，直到`d==1`

```Cpp
int a[maxNum];

void shellSort(){
	for(int d=n/2;d>=1;d/=2){    //枚举增量
		for(int i=1+d;i<=n;i++){    //从第一组的第二个数开始
			int x=a[i];    //x就是某个组中乱序区的第一个数,这个组中有序区中最后一个数就是a[i-d]
			int j;
			for(j=i-d;j>=1;j-=d){    //从有序区最后一个数开始倒着遍历
				if(a[j]<=x)break;
				a[j+d]=a[j];
			}
			a[j+d]=x;
		}
	}
}
```

最坏时间复杂度$O(N^2)$，最好时间复杂度$O(N^{1.3})$，空间复杂度$O(1)$，就地排序，不稳定（因为相同的数据可能分在不同组）
