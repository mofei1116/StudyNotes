> 基于二叉树，实现3阶或4阶B树的的数据结构（按序拆分，添加颜色），相较于AVL树更适合动态查找

# 基本概念

以B树为基础，若一个节点中有一个以上的数据，只留一个数据，其余的数据按顺序拆分作为该节点的孩子，拆分出来的节点标记为红色

- 内部终端节点：没有孩子的节点
- 叶子节点：失败节点（外部节点），内部终端节点的空孩子节点
- 节点的黑高$bh$：从某个节点出发，到下一个叶子节点的简单路径中黑色节点的个数（不算起点）
- 树的黑高：根节点的黑高

# 性质

1. 根节点一定是黑色，根节点不可能通过拆分得到
2. 叶子节点一定是黑色的
3. 不存在相邻的两个红色节点，红色节点的孩子和父亲一定是黑色的
4. 对于每个节点，从该节点到下面任意一个叶子节点的简单路径上，含有的黑色节点的个数相同
	因为原始的B树绝对平衡，黑色节点对应原始B树的原有的节点；假设一条简单路径上黑色节点的个数为$n$，则该路径上的红色节点的个数最多为$n-1$，因为除了叶子节点每个黑色节点都可能拆分出一个红色节点
5. 红黑树也是二叉排序树，有顺序性
6. 红黑树的黑高就是其原始B树的高度
7. 平衡性：高的子树的高度不超过矮的子树的高度的两倍，从根节点到叶子节点的最长路径长度不大于最短路径长度的两倍
	因为最短路径长度就是黑高，最长路径长度就是黑高的两倍（除了叶子节点每个黑色节点都拆分出一个红色节点），相较于AVL树的平衡性较宽松
8. $n$个内部节点的红黑树高度$h\le 2log(n+1)$
	推导：红黑树高度$bh\le h\le 2bh$，所以$bh\ge h/2$，对于一颗黑高为$bh$的红黑树，最少节点数为$2^{bh}-1$（没有红色节点的满二叉树），即$n\ge 2^{bh}-1$，即$bh\le log(n+1)$，又因为$bh\ge h/2$，所以$h\le 2log(n+1)$

# 结构

```Cpp
#define RED 1
#define BLACK 0

struct RBTnode{
	int data;
	RBTnode* parent;
	RBTnode* leftChild;
	RBTnode* rightChild;
	int color;
}
```

# 插入

1. 新建一个节点按照BST的插入插到RBT中
2. 节点的初始颜色赋为**红色**，若赋为黑色，会破坏任意简单路径黑色节点个数相同的性质
3. 判断是否破环性质
	1. 在空树中插入一个节点，破坏了根节点为黑色节点的性质，直接将节点标记为黑色
	2. 节点的父亲是红色节点，破坏了红色节点不相邻的性质；RBT是由原始B树拆分得到的，将插入一个节点破坏性质看成是拆分B树时拆分错误，先将RBT合成B树，看成是在B树中插入新节点，B树调整后，再拆分成正确的RBT树

## 调整分类

插入节点是红色节点，且其父节点是红色节点

- 新插入的节点`k`：红色
- `k`的父节点`p`：红色
- `k`的爷爷节点`g`：黑色
- `k`的叔叔节点`u`：`u`为空时为黑色，`u`不为空时为红色
	因为插入前`p`不可能有非空的儿子（黑路同性质），若`u`为非空黑色会破坏`g`的黑路同性质
如果向上继续调整，新的`u`节点不空时可能为黑色或红色

### 叔叔节点为红色

除了`k`节点，`p`节点和`u`节点和`g`节点全部变颜色
若`g`节点的父亲是黑色节点，调整结束；若`g`的父节点是红色节点，将`g`节点看成是新的`k`节点，继续调整，直到`k`为根节点，将根节点变黑

### 叔叔节点为黑色

> 叔叔节点可能空可能非空（一开始只可能为黑空）

调整过程中不需要考虑`u`

#### LL

> `p`是`g`的左孩子，`k`是`p`的左孩子

1. 对`g`右旋
2. `g`变红，`p`变黑

#### LR

> `p`是`g`的左孩子，`k`是`p`的右孩子

1. 对`p`左旋
2. 对`g`右旋
3. `g`变红，`k`变黑

#### RR

> `p`是`g`的右孩子，`k`是`p`的右孩子

1. 对`g`左旋
2. `g`变红，`p`变黑

#### RL

> `p`是`g`的右孩子，`k`是`p`的左孩子

1. 对`p`右旋
2. 对`g`左旋
3. `g`变红，`k`变黑

## 实现

```Cpp
RBTnode* rightRotate(RBTnode* root,RBTnode* t){
	RBTnode* L=t->leftChild;
	RBTnode* f=t->parent;
	RBTnode* Lr=L->rightChild;
	L->rightChild=t;
	t->parent=L;
	t->leftChild=Lr;
	if(Lr)Lr->parent=t;
	L->parent=f;
	if(f){
		if(f->leftChild==t)f->leftChild=L;
		else f->rightChild=L;
	}
	else {
		root=L;    //更新根节点
	}
	return root;
}

RBTnode* leftRotate(RBTnode* root,RBTnode* t){
	RBTnode* R=t->rightChild;
	RBTnode* f=t->parent;
	RBTnode* Rl=R->leftChild;
	R->leftChild=t;
	t->parent=R;
	t->rightChild=Rl;
	if(Rl)Rl->parent=t;
	R->parent=f;
	if(f){
		if(f->leftChild==t)f->leftChild=R;
		else f->rightChild=R;
	}
	else {
		root=R;    //跟新根节点
	}
	return root;
}

RBTnode* insertAdjust(RBTnode* root,RBTnode* k){    //k破坏了平衡
	RBTnode* p=nullptr;
	RBTnode* g=nullptr;
	RBTnode* u=nullptr;
	while(k!=root&&k->parent->color==RED){
		p=k->parent;
		g=p->parent;
		u=(p==g->leftChild)?g->rightChild:g->leftChild;
		if(u&&u->color==RED){    //叔叔为红色
			p->color=BLACK;
			u->color=BLACK;
			g->color=RED;
			k=g;
		}
		else {    //叔叔为黑色（不一定存在）
			if(g->leftChild==p){
				if(p->leftChild==k){    //LL
					root=rightRotate(root,g);
					g->color=RED;
					p->color=BLACK;
				}
				else {    //LR
					root=leftRotate(root,p);
					root=rightRotate(root,g);
					g->color=RED;
					k->color=BLACK;
				}
			}
			else {
				if(p->rightChild==k){    //RR
					root=leftRotate(root,g);
					g->color=RED;
					p->color=BLACK;
				}
				else {    //RL
					root=rightRotate(root,p);
					root=leftRotate(root,g);
					g->color=RED;
					k->color=BLACK;
				}
			}
			break;    //没有break也不影响红黑树的正确性
		}
	}
	if(k==root)k->color=BLACK;    //将根节点变黑
	return root;
}

RBTnode* insertNode(RBTnode* root,int d){
	//新建节点
	RBTnode* k=new RBTnode;
	k->data=d;
	k->parent=k->leftChild=k->rightChild=nullptr;
	k->color=RED;
	//插入空树
	if(root==nullptr){
		k->color=BLACK;
		root=k;
		return root;
	}
	//BST非递归插入
	RBTnode* p=root,*pf=nullptr;
	while(p){
		pf=p;
		if(d<p->data){
			p=p->leftChild;
		}
		else {
			p=p->rightChild;
		}
	}
	k->parent=pf;
	if(d<pf->data)pf->leftChild=k;
	else pf->rightChild=k;
	//需要调整
	if(k->parent->color==RED){
		root=Adjust(root,k);
	}
	return root;
}
```

# 删除

根据BST的删除，若要删除的节点度为1或0，让其儿子替换这个节点；若要删除的节点的度为2，找到该节点的中序遍历前驱或后继节点，数据复制到要删除的节点，然后去删除该节点的前驱或后继节点，所以最终要删除的节点的度为1或0

要删除的节点为`k`，要删除的节点的儿子为`c`（可能为空）：
1. `k`为红色，`c`为黑色，删除后不破坏性质
2. `k`为黑色，`c`为红色，删除后破坏黑路同性质，若`k`的父节点为红色会破坏两个红色节点不相邻的性质，如果`k`是根节点，会破坏根节点不为红色的性质
	**调整**：只需要把`c`变为黑色
3. `k`为黑色，`c`为黑色，删除后破坏黑路同性质；看成是原始B树删除后拆分成红黑树错误，先还原成B树，在B树上删除后再拆分成正确的红黑树

## 调整分类

要删除的节点为黑色，要删除的节点的孩子也是黑色

- 要删除的节点`k`：黑色
- `k`的孩子`c`：黑色，`k`删除后`c`继承`k`的位置和关系
- `k`的父亲`p`：删除后是`c`的父亲，红色或黑色
- `k`的兄的`s`：删除后是`c`的兄弟，红色或黑色

删除后：

### `c`在右，`s`在左

#### `s`为黑色

##### `s`至少有一个红色孩子

###### `s`左孩子是红色

> 看成是LL

设`s`的左孩子为`redChild`
1. `s`变成`p`的颜色
2. 对`p`右旋
3. `redChild`和`p`变为黑色

###### `s`右孩子是红色

> 看成是LR

设`s`的右孩子为`redChild`
1. `s`左旋
2. `s`变为红色，`redChild`变为黑色，交换`s`和`redChild`
3. 执行LL调整
	1. `s`变成`p`的颜色
	2. 对`p`右旋
	3. `redChild`和`p`变为黑色

##### `s`没有红色孩子

- 双黑节点：删除节点`k`时，认为`k`的颜色留下了，`c`替换`k`时，`c`具有两层黑色；双黑节点是逻辑上的概念，双黑节点对$bh$的贡献是2

把删除后的`c`看成双黑节点，将`s`和`c`一起褪一层黑色，`c`褪一层黑色还是黑色，`s`褪一层黑色变为红色，褪掉的黑色给`p`；若`p`原来是红色，`p`变为黑色，若`p`原来是黑色，`p`变为双黑节点，将`p`看作新的要调整的`c`节点

#### `s`为红色

`p`和`s`的孩子一定是黑色

1. 对`p`右旋
2. `s`变为黑色，`p`变为红色
3. `s`指向`p`的左孩子
4. 执行`s`为黑色的调整

### `c`在左，`s`在右

#### `s`为黑色

##### `s`至少有一个红色孩子

###### `s`右孩子是红色

> 看成是RR

设`s`的右孩子为`redChild`
1. `s`变成`p`的颜色
2. 对`p`左旋
3. `redChild`和`p`变为黑色

###### `s`左孩子是红色

> 看成是RL

设`s`的左孩子为`redChild`
1. `s`右旋
2. `s`变为红色，`redChild`变为黑色，交换`s`和`redChild`
3. 执行RR调整
	1. `s`变成`p`的颜色
	2. 对`p`左旋
	3. `redChild`和`p`变为黑色

##### `s`没有红色孩子

同理，
把删除后的`c`看成双黑节点，将`s`和`c`一起褪一层黑色，`c`褪一层黑色还是黑色，`s`褪一层黑色变为红色，褪掉的黑色给`p`；若`p`原来是红色，`p`变为黑色，若`p`原来是黑色，`p`变为双黑节点，将`p`看作新的要调整的`c`节点

#### `s`为红色

`p`和`s`的孩子一定是黑色

1. 对`p`左旋
2. `s`变为黑色，`p`变为红色
3. `s`指向`p`的右孩子
4. 执行`s`为黑色的调整

## 实现

```Cpp
RBTnode* deleteAdjust(RBTnode* root,RBTnode* c,RBTnode* p){//c,p不同时为空
	RBTnode* s=nullptr;
	while(c!=root&&(!c||c->color==BLACK)){    //c是黑色
		if(p->rightChild==c){    //s在左，c在右
			s=p->leftChild;    //s一定不为空（若为空不满足黑路同）
			if(s->color==RED){    //s为红色
				root=rightRotate(root,p);
				p->color=RED;
				s->color=BLACK;
				s=p->leftChild;
			}
			//s为黑色且不为空
			if((!s->leftChild||s->leftChild->color==BLACK)&&
			(!s->rightChild||s->rightChild->color==BLACK)){
			//s没有红色孩子
				s->color=RED;
				c=p;
				p=c->parent;
			}
			else {    //s至少有一个红色孩子
				RBTnode* r=nullptr;
				if(!s->leftChild||s->leftChild->color==BLACK){    //LR
					r=s->rightChild;
					root=leftRotate(root,s);
					s->color=RED;
					r->color=BLACK;
					RBTnode* temp=s;
					s=r;
					r=temp;
				}
				//LL
				r=s->leftChild;
				s->color=p->color;
				root=rightRotate(root,p);
				p->color=r->color=BLACK;
				break;
			}
		}
		else {    //s在右，c在左
			s=p->rightChild;
			if(s->color==RED){    //s为红色
				root=leftRotate(root,p);
				p->color=RED;
				s->color=BLACK;
				s=p->rightChild;
			}
			//s为黑色且不为空
			if((!s->leftChild||s->leftChild->color==BLACK)&&
			(!s->rightChild||s->rightChild->color==BLACK)){
			//s没有红色孩子
				s->color=RED;
				c=p;
				p=c->parent;
			}
			else {    //s至少有一个红色孩子
				RBTnode* r=nullptr;
				if(!s->rightChild||s->rightChild->color==BLACK){    //RL
					r=s->leftChild;
					root=rightRotate(root,s);
					s->color=RED;
					r->color=BLACK;
					RBTnode* temp=s;
					s=r;
					r=temp;
				}
				//RR
				r=s->rightChild;
				s->color=p->color;
				root=leftRotate(root,p);
				p->color=r->color=BLACK;
				break;
			}
		}
	}
	if(c&&c->color==RED)c->color=BLACK;
	return root;
}

RBTnode* deleteNode(RBTnode* root,int d){
	if(!root)return root;
	//查找d
	RBTnode* k=root;
	while(k&&k->data!=d){
		if(d<k->data)k=k->leftChild;
		else k=k->rightChild;
	}
	if(!k)return root;    //查找失败
	if(k->leftChild&&k->rightChild){    //要删除的节点度为2
		RBTnode* p=k->rightChild;
		while(p->leftChild)p=p->leftChild;    //找后继节点
		k->data=p->data;
		k=p;
	}
	//删除k节点
	RBTnode* c=k->leftChild?k->leftChild:k->rightChild;
	RBTnode* p=k->parent;
	if(c)c->parent=p;
	if(p){
		if(p->leftChild==k)p->leftChild=c;
		else p->rightChild=c;
	}
	else {
		root=c;
	}
	int kc=k->color;
	delete k;
	k=nullptr;
	//调整
	if(!root)return root;    //空树不需要调整
	if(kc==BLACK){   //要删除的节点k是黑色
		root=deleteAdjust(root,c,p);
	}
	return root;
}
```
