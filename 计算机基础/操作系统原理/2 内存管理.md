# 多任务

策略一：将内存数据全部拷贝到磁盘空间，下一次在CPU中运行时再将磁盘中的内存数据全部拷贝到内存上

策略二：将内存分区域，不同程序的内存区域不重合；程序编译时确定**地址偏移量**，链接器链接时确定实际的地址

# 内存分配

## 连续分配

连续分配：给进程分配一块连续的物理内存，每个进程都有一个基地址作为标识，程序中只需要用相对地址

1. 单一连续分配：将内存全部分配给进程，无外部碎片，有内部碎片
2. 固定分区分配：给进程分配固定大小的内存区域，无外部碎片，有内部碎片
3. 动态分区分配：有外部碎片，无内部碎片
	1. 首次适应算法：将空闲区域的起始地址递增排列，找到第一个合适的将进程放进去；性能好，开销低，低地址大分区快速被用完
	2. 邻近适应算法：将空闲区域的起始地址递增排列，每次从上次查找结束的位置开始查找第一个合适的，大分区快速被用完
	3. 最佳适应算法：将空闲区域按区域大小排列，找到最小的满足的区域，产生大量小的外部碎片
	4. 最坏适应算法：将空闲区域按区域大小排列，找到最大的满足的区域，减少了小的外部碎片，大分区快速被用完

## 非连续分配

非连续分配：分页管理，页表，段表，将程序分散地放入物理内存，需要转换，空间利用率更高

- 基本分页：程序运行前，所有页面被一次性地装入内存
- 请求分页：程序运行时，部分页面加载到内存，访问不存在的页面时，考虑置换算法

**虚拟内存**分为多个**页**（从0号页到n号页），虚拟内存的页是**连续**的，映射到物理内存上的**页框**（内存块）是不连续的

**页表**存放n个**页表项**，包含从**页号**（虚拟内存）到**页框号**（物理内存）的映射，页表通常放在内存上或TLB上

逻辑地址：页号 + 页内地址

物理地址：页号对应的页框号 + 页内地址

一个虚拟地址对页的大小（$2^{x}$）取**除数**得到页号，取**余数**得到页内地址，即虚拟地址的后$x$位表示页内地址，前面的位表示页号

由MMU（内存管理单元）管理虚拟内存到物理内存的映射和管理
